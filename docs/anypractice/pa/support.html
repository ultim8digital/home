ਐਪ ਦਾ ਵਰਜਨ, iOS ਵਰਜਨ, ਚੁਣਿਆ AI ਕਨੈਕਸ਼ਨ ਅਤੇ ਗਲਤੀ ਸੁਨੇਹਾ ਦੱਸੋ। API ਕੁੰਜੀਆਂ, Apple ਪਾਸਵਰਡ, ਖਰੀਦ ਦੇ ਪ੍ਰਮਾਣੀਕਰਨ ਵੇਰਵੇ ਜਾਂ ਨਿੱਜੀ ਦਸਤਾਵੇਜ਼ ਨਾ ਭੇਜੋ।

ਤੁਹਾਡੀ ਸਮੱਗਰੀ

ਸਮੱਗਰੀ ਇੰਪੋਰਟ ਜਾਂ ਪੇਸਟ ਕਰੋ, ਸਿੱਖਣ ਦਾ ਢੰਗ ਚੁਣੋ ਅਤੇ AI ਕਨੈਕਸ਼ਨ ਜਾਂਚੋ। ਸਰਗਰਮ Pro ਤੋਂ ਬਿਨਾਂ ਬਣਾਉਣ ਲਈ ਆਪਣੀ API ਕੁੰਜੀ ਚਾਹੀਦੀ ਹੈ। ਜਦੋਂ ਤੱਕ ਤੁਸੀਂ ਸਪਸ਼ਟ ਤੌਰ ਉੱਤੇ ਹੋਰ ਪ੍ਰਦਾਤਾ ਨਹੀਂ ਚੁਣਦੇ, Pro ਡਿਫੌਲਟ ਤੌਰ ਉੱਤੇ ਸਾਡੀ ਸੇਵਾ ਵਰਤਦਾ ਹੈ। ਜੰਤਰ ਅਤੇ ਸਰੋਤ ਤੇ ਸਵਾਲਾਂ ਦੀਆਂ ਦੋਵੇਂ ਭਾਸ਼ਾਵਾਂ ਸਮਰਥਿਤ ਹੋਣ ਉੱਤੇ ਸਰੋਤ-ਅਧਾਰਿਤ ਫਲੈਸ਼ਕਾਰਡਾਂ ਦੇ ਖਰੜਿਆਂ ਲਈ Apple Intelligence ਸਿਰਫ਼ Pro ਨਾਲ ਉਪਲਬਧ ਹੈ। ਪਾਠ, ਸਾਰ ਅਤੇ ਕਵਿਜ਼ ਬਣਾਉਣ ਲਈ ਕਲਾਊਡ ਕਨੈਕਸ਼ਨ ਚਾਹੀਦਾ ਹੈ। Pro ਦੀ ਮਿਆਦ ਮੁੱਕਣ ਉੱਤੇ Pro ਰਾਹੀਂ ਬਣਾਉਣਾ ਰੁਕਦਾ ਹੈ; Apple ਅਣਉਪਲਬਧ ਹੋਣ ਉੱਤੇ ਚੁਣਿਆ Apple ਰਾਹ ਰੁਕਦਾ ਹੈ। ਐਪ ਪ੍ਰਦਾਤਾ ਆਪਣੇ ਆਪ ਨਹੀਂ ਬਦਲਦਾ। ਸੰਭਾਲੇ ਪਾਠ ਅਤੇ ਅਭਿਆਸ ਆਫਲਾਈਨ ਚੱਲਦੇ ਹਨ।

ਫੋਟੋਆਂ ਅਤੇ PDF

ਸਾਫ਼ ਅਤੇ ਚੰਗੀ ਰੋਸ਼ਨੀ ਵਾਲੀ ਫ਼ੋਟੋ ਵਰਤੋ ਅਤੇ ਪਛਾਣਿਆ ਪਾਠ ਜਾਂਚੋ। Pro ਪਾਠਾਂ ਲਈ ਅਸਲ ਫ਼ੋਟੋ ਜਾਂ ਚੁਣੇ ਪੂਰੇ PDF ਪੰਨਿਆਂ ਦੀ ਸਪਸ਼ਟ ਪੁਸ਼ਟੀ ਕਰ ਸਕਦੇ ਹੋ; ਪੂਰੇ ਪੰਨੇ ਵਿੱਚ ਨਾ ਚੁਣਿਆ ਪਾਠ ਵੀ ਹੋ ਸਕਦਾ ਹੈ। ਨਿੱਜੀ ਪ੍ਰਦਾਤਾ ਅਤੇ ਸਰੋਤ-ਕਾਰਡ ਬਣਾਉਣਾ ਸਿਰਫ਼ ਪਾਠ ਵਰਤਦੇ ਹਨ।

AnyPractice Pro — ਸਿਫ਼ਾਰਸ਼ੀ

ਬਿਹਤਰੀਨ ਮਾਡਲਾਂ ਨਾਲ ਪਾਠ, ਵਿਆਖਿਆਵਾਂ, ਸਾਰਾਂਸ਼ ਅਤੇ ਅਭਿਆਸ ਬਣਾਓ।

Pro ਕਲਾਊਡ ਸੇਵਾ ਵਰਤਦੇ ਸਮੇਂ: Pro ਵਿੱਚ ਹਰ UTC ਕੈਲੰਡਰ ਮਹੀਨੇ ਵਿੱਚ ਸ਼ੁਰੂ ਕੀਤੀਆਂ ਵੱਧ ਤੋਂ ਵੱਧ 60 ਬਣਾਉਣ ਦੀਆਂ ਬੇਨਤੀਆਂ ਅਤੇ ਹਰ UTC ਦਿਨ ਵੱਧ ਤੋਂ ਵੱਧ 5 ਸ਼ਾਮਲ ਹਨ। ਪੂਰੀ ਸੇਵਾ ਦੀ ਵਰਤੋਂ ਅਤੇ ਬਜਟ ਦੀਆਂ ਹੱਦਾਂ ਕਾਰਨ ਤੁਹਾਡਾ ਨਿੱਜੀ ਕੋਟਾ ਮੁੱਕਣ ਤੋਂ ਪਹਿਲਾਂ ਸਮੱਗਰੀ ਬਣਾਉਣਾ ਅਸਥਾਈ ਤੌਰ 'ਤੇ ਰੁਕ ਸਕਦਾ ਹੈ। ਸ਼ੁਰੂ ਹੋਈਆਂ ਬੇਨਤੀਆਂ ਅਸਫਲ ਜਾਂ ਰੁਕਣ ਉੱਤੇ ਵੀ ਗਿਣੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਸੰਭਾਲੀ ਸਮੱਗਰੀ ਆਫਲਾਈਨ ਉਪਲਬਧ ਰਹਿੰਦੀ ਹੈ।

ਅਮਰੀਕੀ ਕੀਮਤਾਂ: ਸਵੈਚਲਿਤ ਨਵੀਨੀਕਰਨ ਨਾਲ ਮਹੀਨੇ ਦੇ $6.99 ਜਾਂ ਸਾਲ ਦੇ $49.99। ਸਥਾਨਕ ਕੀਮਤ, ਉਪਲਬਧਤਾ ਅਤੇ ਅੰਤਿਮ ਸ਼ਰਤਾਂ App Store ਵਿੱਚ ਦਿਖਾਈਆਂ ਜਾਂਦੀਆਂ ਹਨ। Apple ਖਾਤੇ ਵਿੱਚ ਪ੍ਰਬੰਧਨ ਜਾਂ ਰੱਦ ਕਰੋ; ਐਪ ਵਿੱਚ ਖਰੀਦਾਂ ਮੁੜ ਬਹਾਲ ਕਰੋ।

ਸਰਗਰਮ Pro ਤੋਂ ਬਿਨਾਂ ਬਣਾਉਣ ਲਈ ਆਪਣੀ API ਕੁੰਜੀ ਚਾਹੀਦੀ ਹੈ। ਜਦੋਂ ਤੱਕ ਤੁਸੀਂ ਸਪਸ਼ਟ ਤੌਰ ਉੱਤੇ ਹੋਰ ਪ੍ਰਦਾਤਾ ਨਹੀਂ ਚੁਣਦੇ, Pro ਡਿਫੌਲਟ ਤੌਰ ਉੱਤੇ ਸਾਡੀ ਸੇਵਾ ਵਰਤਦਾ ਹੈ। ਜੰਤਰ ਅਤੇ ਸਰੋਤ ਤੇ ਸਵਾਲਾਂ ਦੀਆਂ ਦੋਵੇਂ ਭਾਸ਼ਾਵਾਂ ਸਮਰਥਿਤ ਹੋਣ ਉੱਤੇ ਸਰੋਤ-ਅਧਾਰਿਤ ਫਲੈਸ਼ਕਾਰਡਾਂ ਦੇ ਖਰੜਿਆਂ ਲਈ Apple Intelligence ਸਿਰਫ਼ Pro ਨਾਲ ਉਪਲਬਧ ਹੈ। ਪਾਠ, ਸਾਰ ਅਤੇ ਕਵਿਜ਼ ਬਣਾਉਣ ਲਈ ਕਲਾਊਡ ਕਨੈਕਸ਼ਨ ਚਾਹੀਦਾ ਹੈ। Pro ਦੀ ਮਿਆਦ ਮੁੱਕਣ ਉੱਤੇ Pro ਰਾਹੀਂ ਬਣਾਉਣਾ ਰੁਕਦਾ ਹੈ; Apple ਅਣਉਪਲਬਧ ਹੋਣ ਉੱਤੇ ਚੁਣਿਆ Apple ਰਾਹ ਰੁਕਦਾ ਹੈ। ਐਪ ਪ੍ਰਦਾਤਾ ਆਪਣੇ ਆਪ ਨਹੀਂ ਬਦਲਦਾ। OpenAI, Anthropic, Gemini ਜਾਂ ਅਨੁਕੂਲ ਪ੍ਰਦਾਤਾ ਨਾਲ ਨਿੱਜੀ API ਕੁੰਜੀ ਵਰਤੋ। API ਵਰਤੋਂ ਦਾ ਬਿੱਲ ਪ੍ਰਦਾਤਾ ਵੱਖਰੇ ਤੌਰ ਉੱਤੇ ਲੈਂਦਾ ਹੈ।

ਬਣਾਈ ਸਮੱਗਰੀ ਦੀ ਰਿਪੋਰਟ ਕਰੋ

AI ਗਲਤੀਆਂ ਕਰ ਸਕਦਾ ਹੈ। ਤੁਸੀਂ ਐਪ ਵਿੱਚ ਬਣਾਈ ਸਮੱਗਰੀ ਨੂੰ ਸੋਧ ਜਾਂ ਮਿਟਾ ਸਕਦੇ ਹੋ। ਨੁਕਸਾਨਦੇਹ ਸਮੱਗਰੀ ਦੀ ਰਿਪੋਰਟ ਕਰਨ ਲਈ ਨਿੱਜੀ ਜਾਣਕਾਰੀ ਸ਼ਾਮਲ ਕੀਤੇ ਬਿਨਾਂ ਸਮੱਸਿਆ ਦੱਸੋ।

ਸੰਭਾਲਿਆ ਡਾਟਾ ਹਟਾਓ

ਡੈੱਕ ਮਿਟਾਉਣ ਨਾਲ ਇਸ ਐਪ ਵਿੱਚੋਂ ਉਸ ਦਾ ਸੰਭਾਲਿਆ ਪਾਠ, ਫੋਟੋ ਜਾਂ PDF ਦੀ ਸਥਾਨਕ ਕਾਪੀ, ਬਣਾਈ ਸਮੱਗਰੀ ਅਤੇ ਤਰੱਕੀ ਹਟ ਜਾਵੇਗੀ। ਉਹੀ ਸਮੱਗਰੀ ਵਰਤਣ ਵਾਲੇ ਹੋਰ ਡੈੱਕ ਆਪਣੀਆਂ ਕਾਪੀਆਂ ਰੱਖਣਗੇ। «ਕਨੈਕਸ਼ਨ ਹਟਾਓ» ਸੰਭਾਲੀ ਨਿੱਜੀ ਕੁੰਜੀ ਮਿਟਾਉਂਦਾ ਹੈ। ਇਸ ਐਪ ਤੋਂ ਬਾਹਰ ਦੀਆਂ ਫਾਈਲਾਂ, ਬੈਕਅੱਪ ਅਤੇ ਪ੍ਰਦਾਤਾ ਕੋਲ ਮੌਜੂਦ ਡਾਟਾ ਵੱਖਰੇ ਹਨ।
