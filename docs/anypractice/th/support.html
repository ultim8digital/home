ระบุเวอร์ชันแอป เวอร์ชัน iOS การเชื่อมต่อ AI ที่เลือก และข้อความผิดพลาด อย่าส่งคีย์ API รหัสผ่าน Apple ข้อมูลยืนยันการซื้อ หรือเอกสารส่วนตัว

เนื้อหาของคุณ

นำเข้าหรือวางเนื้อหา เลือกโหมดการเรียนและตรวจสอบการเชื่อมต่อ AI หากไม่มี Pro ที่ใช้งานอยู่ การสร้างเนื้อหาต้องใช้คีย์ API ของคุณเอง Pro จะใช้บริการของเราเป็นค่าเริ่มต้น เว้นแต่คุณจะเลือกผู้ให้บริการรายอื่นด้วยตนเอง Apple Intelligence ใช้ได้เฉพาะกับ Pro เพื่อสร้างร่างบัตรคำจากแหล่งข้อมูล เมื่อรองรับอุปกรณ์และทั้งภาษาของแหล่งข้อมูลและคำถาม การสร้างบทเรียน สรุป และแบบทดสอบต้องใช้การเชื่อมต่อคลาวด์ เมื่อ Pro หมดอายุจะสร้างผ่าน Pro ไม่ได้ หาก Apple ไม่พร้อมใช้งาน เส้นทาง Apple ที่เลือกจะถูกบล็อก แอปไม่เปลี่ยนผู้ให้บริการโดยอัตโนมัติ บทเรียนและแบบฝึกที่บันทึกใช้แบบออฟไลน์ได้

รูปภาพและ PDF

ใช้ภาพคมชัดและมีแสงเพียงพอ แล้วตรวจทานข้อความที่รู้จำ สำหรับบทเรียน Pro คุณสามารถยืนยันรูปต้นฉบับหรือหน้า PDF ที่เลือกแบบเต็มหน้าได้อย่างชัดแจ้ง ทั้งหน้าอาจมีข้อความที่ไม่ได้เลือก การสร้างผ่านผู้ให้บริการส่วนตัวและบัตรคำจากแหล่งข้อมูลใช้เฉพาะข้อความ

AnyPractice Pro — แนะนำ

สร้างบทเรียน คำอธิบาย บทสรุป และแบบฝึกหัดด้วยโมเดลที่ดีที่สุด

เมื่อใช้บริการคลาวด์ Pro: Pro รวมคำขอสร้างเนื้อหาที่เริ่มแล้วสูงสุด 60 ครั้งต่อเดือนปฏิทิน UTC และไม่เกิน 5 ครั้งต่อวัน UTC ข้อจำกัดการใช้งานและงบประมาณโดยรวมของบริการอาจทำให้การสร้างเนื้อหาหยุดชั่วคราวก่อนที่โควตาส่วนตัวของคุณจะหมด คำขอที่เริ่มแล้วจะถูกนับแม้ล้มเหลวหรือถูกขัดจังหวะ เนื้อหาที่บันทึกยังใช้งานแบบออฟไลน์ได้

ราคาในสหรัฐฯ: 6.99 ดอลลาร์สหรัฐต่อเดือน หรือ 49.99 ดอลลาร์สหรัฐต่อปี ต่ออายุอัตโนมัติ ราคาในพื้นที่ การให้บริการ และเงื่อนไขสุดท้ายจะแสดงใน App Store จัดการหรือยกเลิกในบัญชี Apple และกู้คืนการซื้อในแอป

หากไม่มี Pro ที่ใช้งานอยู่ การสร้างเนื้อหาต้องใช้คีย์ API ของคุณเอง Pro จะใช้บริการของเราเป็นค่าเริ่มต้น เว้นแต่คุณจะเลือกผู้ให้บริการรายอื่นด้วยตนเอง Apple Intelligence ใช้ได้เฉพาะกับ Pro เพื่อสร้างร่างบัตรคำจากแหล่งข้อมูล เมื่อรองรับอุปกรณ์และทั้งภาษาของแหล่งข้อมูลและคำถาม การสร้างบทเรียน สรุป และแบบทดสอบต้องใช้การเชื่อมต่อคลาวด์ เมื่อ Pro หมดอายุจะสร้างผ่าน Pro ไม่ได้ หาก Apple ไม่พร้อมใช้งาน เส้นทาง Apple ที่เลือกจะถูกบล็อก แอปไม่เปลี่ยนผู้ให้บริการโดยอัตโนมัติ ใช้คีย์ API ส่วนตัวกับ OpenAI, Anthropic, Gemini หรือผู้ให้บริการที่รองรับ ผู้ให้บริการคิดค่าบริการ API แยกต่างหาก

รายงานเนื้อหาที่สร้างขึ้น

AI อาจทำผิดพลาดได้ คุณสามารถแก้ไขหรือลบสื่อที่สร้างขึ้นในแอปได้ หากต้องการรายงานเนื้อหาที่เป็นอันตราย โปรดอธิบายปัญหาโดยไม่ใส่ข้อมูลส่วนตัว

ลบข้อมูลที่บันทึกไว้

ลบเด็คเพื่อนำข้อความที่บันทึกไว้ สำเนารูปภาพหรือ PDF ในเครื่อง สื่อที่สร้างขึ้น และความคืบหน้าของเด็คนั้นออกจากแอปนี้ เด็คอื่นที่ใช้เนื้อหาเดียวกันจะยังเก็บสำเนาของตนไว้ การลบการเชื่อมต่อจะลบคีย์ส่วนตัวที่บันทึกไว้ ไฟล์นอกแอปนี้ ข้อมูลสำรอง และข้อมูลที่ผู้ให้บริการเก็บไว้เป็นข้อมูลคนละส่วนกัน
