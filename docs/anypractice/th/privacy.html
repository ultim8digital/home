คลังบนอุปกรณ์

ข้อความเพื่อการเรียนที่ดึงออกมา บทเรียน การ์ด และความคืบหน้าจะบันทึกไว้ในแอปนี้บนอุปกรณ์ของคุณ แอปไม่สร้างบัญชี AnyPractice และไม่มีบริการซิงค์คลาวด์ของตนเอง ข้อมูลสำรองของอุปกรณ์อาจรวมข้อมูลแอปที่เก็บไว้บนอุปกรณ์

รูปภาพและ PDF

การอ่านข้อความทำงานบนอุปกรณ์ของคุณ รูปภาพและ PDF ที่นำเข้าจะถูกบันทึกไว้ในเครื่องพร้อมเนื้อหาของคุณด้วย สำหรับบทเรียน Pro คุณสามารถส่งรูปภาพหรือหน้า PDF ที่เลือกแบบเต็มหน้าไปยัง OpenAI หลังจากตรวจทานและยืนยันแล้ว โหมดที่ใช้เฉพาะข้อความจะส่งเฉพาะข้อความที่ตรวจทานแล้ว

ผู้ให้บริการ AI

หากไม่มี Pro ที่ใช้งานอยู่ การสร้างเนื้อหาต้องใช้คีย์ API ของคุณเอง Pro จะใช้บริการของเราเป็นค่าเริ่มต้น เว้นแต่คุณจะเลือกผู้ให้บริการรายอื่นด้วยตนเอง Apple Intelligence ใช้ได้เฉพาะกับ Pro เพื่อสร้างร่างบัตรคำจากแหล่งข้อมูล เมื่อรองรับอุปกรณ์และทั้งภาษาของแหล่งข้อมูลและคำถาม การสร้างบทเรียน สรุป และแบบทดสอบต้องใช้การเชื่อมต่อคลาวด์ เมื่อ Pro หมดอายุจะสร้างผ่าน Pro ไม่ได้ หาก Apple ไม่พร้อมใช้งาน เส้นทาง Apple ที่เลือกจะถูกบล็อก แอปไม่เปลี่ยนผู้ให้บริการโดยอัตโนมัติ ใช้คีย์ API ส่วนตัวกับ OpenAI, Anthropic, Gemini หรือผู้ให้บริการที่รองรับ ผู้ให้บริการคิดค่าบริการ API แยกต่างหาก เมื่อใช้คีย์ API ของคุณ ระบบจะส่งเฉพาะข้อความที่เลือกและคำสั่งในการสร้างเนื้อหาไปยังผู้ให้บริการและโมเดลที่คุณยืนยันโดยตรง คีย์ของคุณเก็บอยู่ใน Keychain ของอุปกรณ์นี้ ผู้ให้บริการอาจเก็บคำขอไว้ตามข้อกำหนดของตน AnyPractice ไม่สามารถลบสำเนาที่ผู้ให้บริการนั้นเก็บไว้แล้วได้

Apple Intelligence

ตัวเลือกนี้ต้องมีการสมัคร Pro ที่ใช้งานอยู่ Apple Intelligence สร้างแฟลชการ์ดจากสื่อต้นฉบับบนอุปกรณ์ที่รองรับ การสร้างเนื้อหาและการแปลที่รองรับทำงานบนอุปกรณ์ โดยอาจต้องดาวน์โหลดทรัพยากรภาษา

AnyPractice Pro

เมื่อใช้บริการคลาวด์ Pro: เมื่อใช้ Pro ข้อความที่เลือกและหน้าต้นฉบับใด ๆ ที่คุณยืนยันจะส่งผ่าน AnyPractice บน Vercel ไปยัง OpenAI ไฟล์ต้นฉบับจะถูกประมวลผลสำหรับคำขอนั้นโดยไม่มีคลังไฟล์บนเซิร์ฟเวอร์ Apple จัดการการชำระเงิน ส่วนเซิร์ฟเวอร์ตรวจสอบการสมัครสมาชิกและเก็บตัวระบุและตัวนับการใช้งาน บริการของผู้ให้บริการและบริการโฮสติ้งจัดการข้อมูลตามนโยบายของตนเอง

ลบข้อมูลที่บันทึกไว้

ลบเด็คเพื่อนำข้อความที่บันทึกไว้ สำเนารูปภาพหรือ PDF ในเครื่อง สื่อที่สร้างขึ้น และความคืบหน้าของเด็คนั้นออกจากแอปนี้ เด็คอื่นที่ใช้เนื้อหาเดียวกันจะยังเก็บสำเนาของตนไว้ การลบการเชื่อมต่อจะลบคีย์ส่วนตัวที่บันทึกไว้ ไฟล์นอกแอปนี้ ข้อมูลสำรอง และข้อมูลที่ผู้ให้บริการเก็บไว้เป็นข้อมูลคนละส่วนกัน

บันทึกบริการและการเก็บข้อมูลของผู้ให้บริการ

เมื่อใช้บริการคลาวด์ Pro: Pro ส่งเนื้อหาที่คุณยืนยันผ่าน Vercel ไปยัง OpenAI เราไม่มีคลังไฟล์การเรียนบนเซิร์ฟเวอร์และไม่จงใจบันทึกเนื้อหาการเรียนในล็อก แต่ไม่ได้หมายความว่าไม่มีการเก็บข้อมูล นโยบายผู้ให้บริการและโครงสร้างพื้นฐานยังมีผล คำขอ OpenAI ใช้ store:false เนื้อหาการตรวจสอบการใช้งานในทางที่ผิดตามค่าเริ่มต้นอาจถูกเก็บได้ถึง 30 วัน โดยมีข้อยกเว้นด้านกฎหมายและความปลอดภัย การเข้าถึงสมาชิก ความปลอดภัย และขีดจำกัดใช้ธุรกรรม Apple ที่ลงนาม ตัวระบุสมาชิก/คำขอแบบแฮชที่คงที่ และตัวนับ UTC ตัวระบุเหล่านี้ไม่ใช่ข้อมูลนิรนาม ตัวนับรายวันหมดอายุ 3 วันหลังอัปเดตล่าสุด รายเดือนหลัง 35 วัน ส่วนค่าแฮชตรวจคำขอซ้ำไม่หมดอายุอัตโนมัติ การลบชุดบัตรในเครื่องไม่ลบบันทึกเหล่านี้ บันทึกของผู้ให้บริการ ข้อมูลสำรองระบบปฏิบัติการ หรือจดหมายโต้ตอบกับฝ่ายช่วยเหลือ ติดต่อเราเรื่องคำขอข้อมูลบริการ และอย่าส่งคีย์ลับหรือรหัสผ่านเด็ดขาด
