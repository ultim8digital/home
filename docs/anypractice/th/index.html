การอ่านข้อความทำงานบนอุปกรณ์ของคุณ รูปภาพและ PDF ที่นำเข้าจะถูกบันทึกไว้ในเครื่องพร้อมเนื้อหาของคุณด้วย สำหรับบทเรียน Pro คุณสามารถส่งรูปภาพหรือหน้า PDF ที่เลือกแบบเต็มหน้าไปยัง OpenAI หลังจากตรวจทานและยืนยันแล้ว โหมดที่ใช้เฉพาะข้อความจะส่งเฉพาะข้อความที่ตรวจทานแล้ว

หากไม่มี Pro ที่ใช้งานอยู่ การสร้างเนื้อหาต้องใช้คีย์ API ของคุณเอง Pro จะใช้บริการของเราเป็นค่าเริ่มต้น เว้นแต่คุณจะเลือกผู้ให้บริการรายอื่นด้วยตนเอง Apple Intelligence ใช้ได้เฉพาะกับ Pro เพื่อสร้างร่างบัตรคำจากแหล่งข้อมูล เมื่อรองรับอุปกรณ์และทั้งภาษาของแหล่งข้อมูลและคำถาม การสร้างบทเรียน สรุป และแบบทดสอบต้องใช้การเชื่อมต่อคลาวด์ เมื่อ Pro หมดอายุจะสร้างผ่าน Pro ไม่ได้ หาก Apple ไม่พร้อมใช้งาน เส้นทาง Apple ที่เลือกจะถูกบล็อก แอปไม่เปลี่ยนผู้ให้บริการโดยอัตโนมัติ ใช้คีย์ API ส่วนตัวกับ OpenAI, Anthropic, Gemini หรือผู้ให้บริการที่รองรับ ผู้ให้บริการคิดค่าบริการ API แยกต่างหาก
