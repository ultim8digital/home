Постачальники ШІ

Без активної підписки Pro для генерації потрібен власний API-ключ. Pro за замовчуванням використовує наш сервіс, якщо ви явно не вибрали іншого провайдера. Apple Intelligence доступний лише з Pro для чернеток карток за джерелами, якщо підтримуються пристрій, мова джерела та мова запитань. Для генерації уроків, підсумків і тестів потрібне хмарне підключення. Завершення Pro блокує генерацію через Pro; недоступність Apple блокує вибраний режим Apple. Застосунок не перемикає провайдерів автоматично. Використовуйте власний API-ключ OpenAI, Anthropic, Gemini або сумісного провайдера. Провайдер окремо стягує плату за використання API.

AnyPractice Pro — рекомендуємо

Загальні обмеження використання та бюджету сервісу можуть призупинити генерацію до вичерпання вашої особистої квоти. Розпочаті запити враховуються навіть за помилки чи переривання.
