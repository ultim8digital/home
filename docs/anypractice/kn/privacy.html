ಈ ಪುಟದಲ್ಲಿ
ಸ್ಥಳೀಯ ಗ್ರಂಥಾಲಯಫೋಟೋಗಳು ಮತ್ತು PDFಗಳುAI ಪೂರೈಕೆದಾರರುApple IntelligenceAnyPractice Proಉಳಿಸಿದ ಡೇಟಾ ತೆಗೆದುಹಾಕಿಸೇವಾ ದಾಖಲೆಗಳು ಮತ್ತು ಪೂರೈಕೆದಾರರ ಸಂಗ್ರಹಸಹಾಯ

ಸ್ಥಳೀಯ ಗ್ರಂಥಾಲಯ

ಹೊರತೆಗೆದ ಅಧ್ಯಯನ ಪಠ್ಯ, ಪಾಠಗಳು, ಕಾರ್ಡ್‌ಗಳು ಮತ್ತು ಪ್ರಗತಿಯನ್ನು ನಿಮ್ಮ ಸಾಧನದ ಈ ಆ್ಯಪ್‌ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ. ಆ್ಯಪ್ AnyPractice ಖಾತೆಯನ್ನು ರಚಿಸುವುದಿಲ್ಲ ಅಥವಾ ತನ್ನದೇ ಕ್ಲೌಡ್ ಸಿಂಕ್ ಒದಗಿಸುವುದಿಲ್ಲ. ಸಾಧನದ ಬ್ಯಾಕಪ್‌ಗಳು ಆ್ಯಪ್‌ನ ಸ್ಥಳೀಯ ಡೇಟಾವನ್ನು ಒಳಗೊಂಡಿರಬಹುದು.

ಫೋಟೋಗಳು ಮತ್ತು PDFಗಳು

ಪಠ್ಯ ಗುರುತಿಸುವಿಕೆ ನಿಮ್ಮ ಸಾಧನದಲ್ಲೇ ನಡೆಯುತ್ತದೆ. ಆಮದು ಮಾಡಿದ ಫೋಟೋಗಳು ಮತ್ತು PDFಗಳನ್ನು ಸಹ ನಿಮ್ಮ ಸಾಮಗ್ರಿಯೊಂದಿಗೆ ಸ್ಥಳೀಯವಾಗಿ ಉಳಿಸಲಾಗುತ್ತದೆ. Pro ಪಾಠಗಳಿಗಾಗಿ, ಪರಿಶೀಲಿಸಿ ದೃಢೀಕರಿಸಿದ ನಂತರ ಫೋಟೋ ಅಥವಾ ಆಯ್ಕೆಮಾಡಿದ ಸಂಪೂರ್ಣ PDF ಪುಟಗಳನ್ನು OpenAIಗೆ ಕಳುಹಿಸಬಹುದು. ಪಠ್ಯಕ್ಕೆ ಮಾತ್ರ ಇರುವ ಮೋಡ್‌ಗಳು ಪರಿಶೀಲಿಸಿದ ಪಠ್ಯವನ್ನು ಮಾತ್ರ ಕಳುಹಿಸುತ್ತವೆ.

AI ಪೂರೈಕೆದಾರರು

ಸಕ್ರಿಯ Pro ಇಲ್ಲದೆ ರಚನೆಗೆ ನಿಮ್ಮದೇ API ಕೀ ಅಗತ್ಯವಿದೆ. ನೀವು ಸ್ಪಷ್ಟವಾಗಿ ಬೇರೆ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆ ಮಾಡದಿದ್ದರೆ Pro ನಮ್ಮ ಸೇವೆಯನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಬಳಸುತ್ತದೆ. ಸಾಧನ ಹಾಗೂ ಮೂಲ ಮತ್ತು ಪ್ರಶ್ನೆಗಳ ಎರಡೂ ಭಾಷೆಗಳಿಗೆ ಬೆಂಬಲವಿದ್ದಾಗ ಮೂಲಾಧಾರಿತ ಫ್ಲ್ಯಾಶ್‌ಕಾರ್ಡ್ ಕರಡುಗಳಿಗಾಗಿ Apple Intelligence Pro ನಲ್ಲಿ ಮಾತ್ರ ಲಭ್ಯ. ಪಾಠಗಳು, ಸಾರಾಂಶಗಳು ಮತ್ತು ರಸಪ್ರಶ್ನೆಗಳ ರಚನೆಗೆ ಕ್ಲೌಡ್ ಸಂಪರ್ಕ ಅಗತ್ಯವಿದೆ. Pro ಅವಧಿ ಮುಗಿದರೆ Pro ರಚನೆ ತಡೆಯಲಾಗುತ್ತದೆ; Apple ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ ಆಯ್ದ Apple ಮಾರ್ಗ ತಡೆಯಲಾಗುತ್ತದೆ. ಆ್ಯಪ್ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬದಲಿಸುವುದಿಲ್ಲ. OpenAI, Anthropic, Gemini ಅಥವಾ ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ವೈಯಕ್ತಿಕ API ಕೀ ಬಳಸಿ. API ಬಳಕೆಗೆ ಪೂರೈಕೆದಾರರು ಪ್ರತ್ಯೇಕ ಶುಲ್ಕ ವಿಧಿಸುತ್ತಾರೆ. ನಿಮ್ಮ API ಕೀಲಿಯನ್ನು ಬಳಸಿದಾಗ, ಆಯ್ದ ಭಾಗಗಳು ಮತ್ತು ರಚನೆಯ ಸೂಚನೆಗಳನ್ನು ಮಾತ್ರ ನೀವು ದೃಢೀಕರಿಸಿದ ಪೂರೈಕೆದಾರ ಮತ್ತು ಮಾದರಿಗೆ ನೇರವಾಗಿ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ನಿಮ್ಮ ಕೀಲಿಯನ್ನು ಈ ಸಾಧನದ Keychainನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಪೂರೈಕೆದಾರರು ತಮ್ಮ ನಿಯಮಗಳ ಪ್ರಕಾರ ವಿನಂತಿಗಳನ್ನು ಉಳಿಸಬಹುದು. ಪೂರೈಕೆದಾರರ ಬಳಿ ಈಗಾಗಲೇ ಇರುವ ಪ್ರತಿಗಳನ್ನು AnyPractice ಅಳಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.

Apple Intelligence

ಈ ಆಯ್ಕೆಗೆ ಸಕ್ರಿಯ Pro ಚಂದಾದಾರಿಕೆ ಅಗತ್ಯವಿದೆ. Apple Intelligence ಬೆಂಬಲಿತ ಸಾಧನಗಳಲ್ಲಿ ಮೂಲಾಧಾರಿತ ಫ್ಲ್ಯಾಶ್‌ಕಾರ್ಡ್‌ಗಳನ್ನು ರಚಿಸುತ್ತದೆ. ರಚನೆ ಮತ್ತು ಬೆಂಬಲಿತ ಅನುವಾದ ಸ್ಥಳೀಯವಾಗಿ ನಡೆಯುತ್ತವೆ; ಭಾಷಾ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಬೇಕಾಗಬಹುದು.

AnyPractice Pro

Pro ಕ್ಲೌಡ್ ಸೇವೆಯನ್ನು ಬಳಸುವಾಗ: Proನಲ್ಲಿ ಆಯ್ಕೆಮಾಡಿದ ಪಠ್ಯ ಮತ್ತು ದೃಢೀಕರಿಸಿದ ಮೂಲ ಪುಟಗಳು Vercelನಲ್ಲಿರುವ AnyPractice ಮೂಲಕ OpenAIಗೆ ತಲುಪುತ್ತವೆ. ಸರ್ವರ್‌ನಲ್ಲಿ ಫೈಲ್ ಲೈಬ್ರರಿ ನಿರ್ಮಿಸದೆ, ಆ ವಿನಂತಿಗಾಗಿ ಮೂಲ ಫೈಲ್‌ಗಳನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲಾಗುತ್ತದೆ. Apple ಪಾವತಿಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ; ಸರ್ವರ್ ನಿಮ್ಮ ಚಂದಾದಾರಿಕೆಯನ್ನು ಪರಿಶೀಲಿಸಿ ಗುರುತುಗಳನ್ನು ಮತ್ತು ಬಳಕೆಯ ಎಣಿಕೆಗಳನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ. ಸೇವಾದಾತರು ಮತ್ತು ಹೋಸ್ಟಿಂಗ್ ಸೇವೆಗಳು ತಮ್ಮದೇ ನೀತಿಗಳ ಪ್ರಕಾರ ಡೇಟಾವನ್ನು ನಿರ್ವಹಿಸುತ್ತವೆ.

ಉಳಿಸಿದ ಡೇಟಾ ತೆಗೆದುಹಾಕಿ

ಡೆಕ್ ಅಳಿಸಿದರೆ ಅದರ ಉಳಿಸಿದ ಪಠ್ಯ, ಫೋಟೋ ಅಥವಾ PDFನ ಸ್ಥಳೀಯ ಪ್ರತಿ, ರಚಿಸಿದ ಸಾಮಗ್ರಿ ಮತ್ತು ಪ್ರಗತಿ ಈ ಆ್ಯಪ್‌ನಿಂದ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತವೆ. ಅದೇ ಸಾಮಗ್ರಿಯನ್ನು ಬಳಸುವ ಇತರ ಡೆಕ್‌ಗಳು ತಮ್ಮ ಪ್ರತಿಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತವೆ. «ಸಂಪರ್ಕ ತೆಗೆದುಹಾಕಿ» ಉಳಿಸಿದ ವೈಯಕ್ತಿಕ ಕೀಯನ್ನು ಅಳಿಸುತ್ತದೆ. ಈ ಆ್ಯಪ್ ಹೊರಗಿನ ಫೈಲ್‌ಗಳು, ಬ್ಯಾಕಪ್‌ಗಳು ಮತ್ತು ಸೇವಾದಾತರ ಬಳಿಯ ಡೇಟಾ ಪ್ರತ್ಯೇಕವಾಗಿವೆ.

ಸೇವಾ ದಾಖಲೆಗಳು ಮತ್ತು ಪೂರೈಕೆದಾರರ ಸಂಗ್ರಹ

Pro ಕ್ಲೌಡ್ ಸೇವೆಯನ್ನು ಬಳಸುವಾಗ: Pro ದೃಢೀಕರಿಸಿದ ವಿಷಯವನ್ನು Vercel ಮೂಲಕ OpenAIಗೆ ಕಳುಹಿಸುತ್ತದೆ. ನಾವು ಸರ್ವರ್‌ನಲ್ಲಿ ಅಧ್ಯಯನ ಕಡತಗಳ ಗ್ರಂಥಾಲಯ ಇಡುವುದಿಲ್ಲ ಅಥವಾ ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಅಧ್ಯಯನ ವಿಷಯವನ್ನು ಲಾಗ್ ಮಾಡುವುದಿಲ್ಲ. ಇದರರ್ಥ ಶೂನ್ಯ ಸಂಗ್ರಹವಲ್ಲ: ಪೂರೈಕೆದಾರರ ಮತ್ತು ಮೂಲಸೌಕರ್ಯ ನೀತಿಗಳು ಅನ್ವಯಿಸುತ್ತವೆ. OpenAI ವಿನಂತಿಗಳು store:false ಬಳಸುತ್ತವೆ; ಸಾಮಾನ್ಯ ದುರುಪಯೋಗ ನಿಗಾದ ವಿಷಯ ಕಾನೂನು/ಸುರಕ್ಷತಾ ವಿನಾಯಿತಿಗಳೊಂದಿಗೆ 30 ದಿನಗಳವರೆಗೆ ಉಳಿಯಬಹುದು. ಚಂದಾದಾರಿಕೆ ಪ್ರವೇಶ, ಸುರಕ್ಷತೆ ಮತ್ತು ಮಿತಿಗಳು ಸಹಿ ಮಾಡಿದ Apple ವಹಿವಾಟುಗಳು, ಸ್ಥಿರ ಹ್ಯಾಶ್ ಮಾಡಿದ ಚಂದಾದಾರಿಕೆ/ವಿನಂತಿ ಗುರುತುಗಳು ಮತ್ತು UTC ಎಣಿಕೆಗಳನ್ನು ಬಳಸುತ್ತವೆ. ಈ ಗುರುತುಗಳು ಅನಾಮಧೇಯವಲ್ಲ. ದೈನಂದಿನ ಎಣಿಕೆಗಳು ಕೊನೆಯ ನವೀಕರಣದ 3 ದಿನಗಳ ಬಳಿಕ, ಮಾಸಿಕ ಎಣಿಕೆಗಳು 35 ದಿನಗಳ ಬಳಿಕ ಮುಕ್ತಾಯಗೊಳ್ಳುತ್ತವೆ; ನಕಲಿ ವಿನಂತಿ ಗುರುತಿಸುವ ಹ್ಯಾಶ್‌ಗಳು ತಾನಾಗಿಯೇ ಮುಕ್ತಾಯಗೊಳ್ಳುವುದಿಲ್ಲ. ಸ್ಥಳೀಯ ಡೆಕ್ ಅಳಿಸುವುದರಿಂದ ಈ ದಾಖಲೆಗಳು, ಪೂರೈಕೆದಾರರ ದಾಖಲೆಗಳು, ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ ಬ್ಯಾಕಪ್‌ಗಳು ಅಥವಾ ಬೆಂಬಲ ಪತ್ರವ್ಯವಹಾರ ಅಳಿಯುವುದಿಲ್ಲ. ಸೇವಾ ದತ್ತಾಂಶ ವಿನಂತಿಗಳಿಗೆ ನಮ್ಮನ್ನು ಸಂಪರ್ಕಿಸಿ; ರಹಸ್ಯ ಕೀ ಅಥವಾ ಪಾಸ್‌ವರ್ಡ್ ಎಂದಿಗೂ ಕಳುಹಿಸಬೇಡಿ.

ಸಹಾಯ

ಕಲಿಯುವವರ ಖಾತೆ, ಜಾಹೀರಾತು SDK ಅಥವಾ ಆ್ಯಪ್‌ಗಳ ನಡುವಿನ ಟ್ರ್ಯಾಕಿಂಗ್ ಇಲ್ಲ. ವೆಬ್‌ಸೈಟ್ ವಿಶ್ಲೇಷಣಾ ಕುಕೀಗಳು ಅಥವಾ ಜಾಹೀರಾತು ಸ್ಕ್ರಿಪ್ಟ್ ಬಳಸುವುದಿಲ್ಲ. GitHub Pages ಸಾಮಾನ್ಯ ಹೋಸ್ಟಿಂಗ್/ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಗಳನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸುತ್ತದೆ. ಬೆಂಬಲ ಇಮೇಲ್ ಮತ್ತು ನೀವು ಆಯ್ದು ಕಳುಹಿಸಿದ ಮಾಹಿತಿ ಉತ್ತರಿಸಲು ಮತ್ತು ಸಮಸ್ಯೆ ಪರಿಶೀಲಿಸಲು ಬಳಕೆಯಾಗುತ್ತದೆ. ಪಾವತಿಗಳನ್ನು Apple ನಿರ್ವಹಿಸುತ್ತದೆ; ನಮಗೆ ಕಾರ್ಡ್ ವಿವರಗಳು ಅಥವಾ Apple ಪಾಸ್‌ವರ್ಡ್ ಸಿಗುವುದಿಲ್ಲ.
