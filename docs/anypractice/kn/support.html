ಆ್ಯಪ್ ಆವೃತ್ತಿ, iOS ಆವೃತ್ತಿ, ಆಯ್ದ AI ಸಂಪರ್ಕ ಮತ್ತು ದೋಷ ಸಂದೇಶ ತಿಳಿಸಿ. API ಕೀಗಳು, Apple ಪಾಸ್‌ವರ್ಡ್‌ಗಳು, ಖರೀದಿ ದೃಢೀಕರಣ ವಿವರಗಳು ಅಥವಾ ಖಾಸಗಿ ದಾಖಲೆಗಳನ್ನು ಕಳುಹಿಸಬೇಡಿ.

ನಿಮ್ಮ ಸಾಮಗ್ರಿ

ವಿಷಯವನ್ನು ಆಮದು ಮಾಡಿ ಅಥವಾ ಅಂಟಿಸಿ, ಕಲಿಕಾ ವಿಧಾನ ಆಯ್ಕೆಮಾಡಿ ಮತ್ತು AI ಸಂಪರ್ಕ ಪರಿಶೀಲಿಸಿ. ಸಕ್ರಿಯ Pro ಇಲ್ಲದೆ ರಚನೆಗೆ ನಿಮ್ಮದೇ API ಕೀ ಅಗತ್ಯವಿದೆ. ನೀವು ಸ್ಪಷ್ಟವಾಗಿ ಬೇರೆ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆ ಮಾಡದಿದ್ದರೆ Pro ನಮ್ಮ ಸೇವೆಯನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಬಳಸುತ್ತದೆ. ಸಾಧನ ಹಾಗೂ ಮೂಲ ಮತ್ತು ಪ್ರಶ್ನೆಗಳ ಎರಡೂ ಭಾಷೆಗಳಿಗೆ ಬೆಂಬಲವಿದ್ದಾಗ ಮೂಲಾಧಾರಿತ ಫ್ಲ್ಯಾಶ್‌ಕಾರ್ಡ್ ಕರಡುಗಳಿಗಾಗಿ Apple Intelligence Pro ನಲ್ಲಿ ಮಾತ್ರ ಲಭ್ಯ. ಪಾಠಗಳು, ಸಾರಾಂಶಗಳು ಮತ್ತು ರಸಪ್ರಶ್ನೆಗಳ ರಚನೆಗೆ ಕ್ಲೌಡ್ ಸಂಪರ್ಕ ಅಗತ್ಯವಿದೆ. Pro ಅವಧಿ ಮುಗಿದರೆ Pro ರಚನೆ ತಡೆಯಲಾಗುತ್ತದೆ; Apple ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ ಆಯ್ದ Apple ಮಾರ್ಗ ತಡೆಯಲಾಗುತ್ತದೆ. ಆ್ಯಪ್ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬದಲಿಸುವುದಿಲ್ಲ. ಉಳಿಸಿದ ಪಾಠ ಮತ್ತು ಅಭ್ಯಾಸ ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ.

ಫೋಟೋಗಳು ಮತ್ತು PDFಗಳು

ಸ್ಪಷ್ಟ, ಚೆನ್ನಾಗಿ ಬೆಳಕಿರುವ ಫೋಟೋ ಬಳಸಿ ಮತ್ತು ಗುರುತಿಸಿದ ಪಠ್ಯ ಪರಿಶೀಲಿಸಿ. Pro ಪಾಠಗಳಿಗೆ ಮೂಲ ಫೋಟೋ ಅಥವಾ ಆಯ್ದ ಸಂಪೂರ್ಣ PDF ಪುಟಗಳನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ದೃಢೀಕರಿಸಬಹುದು; ಪೂರ್ಣ ಪುಟದಲ್ಲಿ ಆಯ್ಕೆಮಾಡದ ಪಠ್ಯವೂ ಇರಬಹುದು. ವೈಯಕ್ತಿಕ ಪೂರೈಕೆದಾರರು ಮತ್ತು ಮೂಲಾಧಾರಿತ ಕಾರ್ಡ್ ರಚನೆ ಪಠ್ಯವನ್ನೇ ಬಳಸುತ್ತವೆ.

AnyPractice Pro — ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ

ಅತ್ಯುತ್ತಮ ಮಾದರಿಗಳ ಮೂಲಕ ಪಾಠಗಳು, ವಿವರಣೆಗಳು, ಸಾರಾಂಶಗಳು ಮತ್ತು ಅಭ್ಯಾಸಗಳನ್ನು ರಚಿಸಿ.

Pro ಕ್ಲೌಡ್ ಸೇವೆಯನ್ನು ಬಳಸುವಾಗ: Pro ಪ್ರತಿ UTC ಕ್ಯಾಲೆಂಡರ್ ತಿಂಗಳಲ್ಲಿ ಗರಿಷ್ಠ 60 ಪ್ರಾರಂಭಿಸಿದ ರಚನಾ ವಿನಂತಿಗಳನ್ನು ಮತ್ತು ಪ್ರತಿ UTC ದಿನಕ್ಕೆ ಹೆಚ್ಚೆಂದರೆ 5 ಅನ್ನು ಒಳಗೊಂಡಿದೆ. ಸೇವೆಯ ಒಟ್ಟಾರೆ ಬಳಕೆ ಮತ್ತು ಬಜೆಟ್ ಮಿತಿಗಳು ನಿಮ್ಮ ವೈಯಕ್ತಿಕ ಕೋಟಾ ಮುಗಿಯುವ ಮೊದಲೇ ರಚನೆಯನ್ನು ತಾತ್ಕಾಲಿಕವಾಗಿ ನಿಲ್ಲಿಸಬಹುದು. ಪ್ರಾರಂಭಿಸಿದ ವಿನಂತಿಗಳು ವಿಫಲವಾದರೂ ಅಥವಾ ಅಡ್ಡಿಯಾದರೂ ಎಣಿಕೆಯಾಗುತ್ತವೆ. ಉಳಿಸಿದ ವಿಷಯ ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಲಭ್ಯವಿರುತ್ತದೆ.

ಅಮೆರಿಕದ ಬೆಲೆ: ಸ್ವಯಂಚಾಲಿತ ನವೀಕರಣದೊಂದಿಗೆ ತಿಂಗಳಿಗೆ $6.99 ಅಥವಾ ವರ್ಷಕ್ಕೆ $49.99. ಸ್ಥಳೀಯ ಬೆಲೆ, ಲಭ್ಯತೆ ಮತ್ತು ಅಂತಿಮ ಷರತ್ತುಗಳು App Storeನಲ್ಲಿ ಕಾಣುತ್ತವೆ. Apple ಖಾತೆಯಲ್ಲಿ ನಿರ್ವಹಿಸಿ ಅಥವಾ ರದ್ದುಮಾಡಿ; ಆ್ಯಪ್‌ನಲ್ಲಿ ಖರೀದಿಗಳನ್ನು ಮರುಸ್ಥಾಪಿಸಿ.

ಸಕ್ರಿಯ Pro ಇಲ್ಲದೆ ರಚನೆಗೆ ನಿಮ್ಮದೇ API ಕೀ ಅಗತ್ಯವಿದೆ. ನೀವು ಸ್ಪಷ್ಟವಾಗಿ ಬೇರೆ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆ ಮಾಡದಿದ್ದರೆ Pro ನಮ್ಮ ಸೇವೆಯನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಬಳಸುತ್ತದೆ. ಸಾಧನ ಹಾಗೂ ಮೂಲ ಮತ್ತು ಪ್ರಶ್ನೆಗಳ ಎರಡೂ ಭಾಷೆಗಳಿಗೆ ಬೆಂಬಲವಿದ್ದಾಗ ಮೂಲಾಧಾರಿತ ಫ್ಲ್ಯಾಶ್‌ಕಾರ್ಡ್ ಕರಡುಗಳಿಗಾಗಿ Apple Intelligence Pro ನಲ್ಲಿ ಮಾತ್ರ ಲಭ್ಯ. ಪಾಠಗಳು, ಸಾರಾಂಶಗಳು ಮತ್ತು ರಸಪ್ರಶ್ನೆಗಳ ರಚನೆಗೆ ಕ್ಲೌಡ್ ಸಂಪರ್ಕ ಅಗತ್ಯವಿದೆ. Pro ಅವಧಿ ಮುಗಿದರೆ Pro ರಚನೆ ತಡೆಯಲಾಗುತ್ತದೆ; Apple ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ ಆಯ್ದ Apple ಮಾರ್ಗ ತಡೆಯಲಾಗುತ್ತದೆ. ಆ್ಯಪ್ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬದಲಿಸುವುದಿಲ್ಲ. OpenAI, Anthropic, Gemini ಅಥವಾ ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ವೈಯಕ್ತಿಕ API ಕೀ ಬಳಸಿ. API ಬಳಕೆಗೆ ಪೂರೈಕೆದಾರರು ಪ್ರತ್ಯೇಕ ಶುಲ್ಕ ವಿಧಿಸುತ್ತಾರೆ.

ರಚಿಸಿದ ವಿಷಯವನ್ನು ವರದಿ ಮಾಡಿ

AI ತಪ್ಪುಗಳನ್ನು ಮಾಡಬಹುದು. ಆ್ಯಪ್‌ನಲ್ಲಿ ರಚಿಸಿದ ವಿಷಯವನ್ನು ಸಂಪಾದಿಸಬಹುದು ಅಥವಾ ಅಳಿಸಬಹುದು. ಹಾನಿಕಾರಕ ವಿಷಯವನ್ನು ವರದಿ ಮಾಡಲು ಖಾಸಗಿ ಮಾಹಿತಿಯನ್ನು ಸೇರಿಸದೆ ಸಮಸ್ಯೆಯನ್ನು ವಿವರಿಸಿ.

ಉಳಿಸಿದ ಡೇಟಾ ತೆಗೆದುಹಾಕಿ

ಡೆಕ್ ಅಳಿಸಿದರೆ ಅದರ ಉಳಿಸಿದ ಪಠ್ಯ, ಫೋಟೋ ಅಥವಾ PDFನ ಸ್ಥಳೀಯ ಪ್ರತಿ, ರಚಿಸಿದ ಸಾಮಗ್ರಿ ಮತ್ತು ಪ್ರಗತಿ ಈ ಆ್ಯಪ್‌ನಿಂದ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತವೆ. ಅದೇ ಸಾಮಗ್ರಿಯನ್ನು ಬಳಸುವ ಇತರ ಡೆಕ್‌ಗಳು ತಮ್ಮ ಪ್ರತಿಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತವೆ. «ಸಂಪರ್ಕ ತೆಗೆದುಹಾಕಿ» ಉಳಿಸಿದ ವೈಯಕ್ತಿಕ ಕೀಯನ್ನು ಅಳಿಸುತ್ತದೆ. ಈ ಆ್ಯಪ್ ಹೊರಗಿನ ಫೈಲ್‌ಗಳು, ಬ್ಯಾಕಪ್‌ಗಳು ಮತ್ತು ಸೇವಾದಾತರ ಬಳಿಯ ಡೇಟಾ ಪ್ರತ್ಯೇಕವಾಗಿವೆ.
