ദിവസവും അൽപ്പം പരിശീലനം

കാര്യങ്ങൾ വ്യക്തമാകട്ടെ.

നിങ്ങളുടെ ഫോട്ടോകൾ, PDF-കൾ, കുറിപ്പുകൾ എന്നിവയിൽ നിന്ന് പാഠങ്ങൾ, ഫ്ലാഷ്‌കാർഡുകൾ, പരിശീലന ക്വിസുകൾ എന്നിവ തയ്യാറാക്കൂ. കരടുകൾ പരിശോധിച്ച് നിങ്ങളുടെ വേഗത്തിൽ പഠിക്കൂ.

നിങ്ങളുടെ സാമഗ്രി. നിങ്ങളുടെ തിരഞ്ഞെടുപ്പ്.

ടെക്സ്റ്റ് തിരിച്ചറിയൽ നിങ്ങളുടെ ഉപകരണത്തിലാണ് നടക്കുന്നത്. ഇറക്കുമതി ചെയ്ത ഫോട്ടോകളും PDF-കളും നിങ്ങളുടെ മെറ്റീരിയലിനൊപ്പം പ്രാദേശികമായി സംരക്ഷിക്കപ്പെടുന്നു. Pro പാഠങ്ങൾക്കായി, അവലോകനം ചെയ്ത് സ്ഥിരീകരിച്ച ശേഷം ഫോട്ടോയോ തിരഞ്ഞെടുത്ത പൂർണ്ണ PDF പേജുകളോ OpenAI-ലേക്ക് അയയ്ക്കാം. ടെക്സ്റ്റ് മാത്രമുള്ള മോഡുകൾ അവലോകനം ചെയ്ത ടെക്സ്റ്റ് മാത്രമേ അയയ്ക്കൂ.

AI സേവനദാതാക്കൾ

സജീവമായ Pro ഇല്ലെങ്കിൽ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ സ്വന്തം API കീ വേണം. മറ്റൊരു സേവനദാതാവിനെ വ്യക്തമായി തിരഞ്ഞെടുക്കാത്തപക്ഷം Pro സ്ഥിരസ്ഥിതിയായി ഞങ്ങളുടെ സേവനം ഉപയോഗിക്കും. ഉപകരണവും ഉറവിടത്തിന്റെയും ചോദ്യങ്ങളുടെയും ഭാഷകളും പിന്തുണയ്ക്കുമ്പോൾ ഉറവിടാധിഷ്ഠിത ഫ്ലാഷ്‌കാർഡ് കരടുകൾക്കായി Apple Intelligence Pro-യിൽ മാത്രം ലഭ്യമാണ്. പാഠങ്ങൾ, സംഗ്രഹങ്ങൾ, ക്വിസുകൾ എന്നിവ സൃഷ്ടിക്കാൻ ക്ലൗഡ് കണക്ഷൻ വേണം. Pro കാലാവധി കഴിഞ്ഞാൽ Pro വഴിയുള്ള സൃഷ്ടിക്കൽ തടയും; Apple ലഭ്യമല്ലെങ്കിൽ തിരഞ്ഞെടുത്ത Apple വഴി തടയും. ആപ്പ് സേവനദാതാവിനെ സ്വയമേവ മാറ്റുകയില്ല. OpenAI, Anthropic, Gemini അല്ലെങ്കിൽ അനുയോജ്യമായ സേവനദാതാവിനൊപ്പം വ്യക്തിഗത API കീ ഉപയോഗിക്കൂ. API ഉപയോഗത്തിന് ദാതാവ് പ്രത്യേകം നിരക്ക് ഈടാക്കുന്നു.

AnyPractice Pro — ശുപാർശ ചെയ്യുന്നത്

മികച്ച മോഡലുകൾ ഉപയോഗിച്ച് പാഠങ്ങൾ, വിശദീകരണങ്ങൾ, സംഗ്രഹങ്ങൾ, പരിശീലനങ്ങൾ എന്നിവ സൃഷ്ടിക്കുക.

Pro ക്ലൗഡ് സേവനം ഉപയോഗിക്കുമ്പോൾ: Pro-യിൽ ഓരോ UTC കലണ്ടർ മാസവും പരമാവധി 60 ആരംഭിച്ച സൃഷ്ടിക്കൽ അഭ്യർത്ഥനകളും UTC ദിവസത്തിൽ പരമാവധി 5-ഉം ഉൾപ്പെടുന്നു. സേവനത്തിന്റെ മൊത്തത്തിലുള്ള ഉപയോഗ, ബജറ്റ് പരിധികൾ നിങ്ങളുടെ വ്യക്തിഗത ക്വോട്ട തീരുന്നതിനുമുമ്പ് സൃഷ്ടിക്കൽ താൽക്കാലികമായി നിർത്തിയേക്കാം. ആരംഭിച്ച അഭ്യർത്ഥനകൾ പരാജയപ്പെട്ടാലും തടസ്സപ്പെട്ടാലും എണ്ണപ്പെടും. സൂക്ഷിച്ച സാമഗ്രി ഓഫ്‌ലൈനിൽ ലഭ്യമാണ്.

അമേരിക്കൻ നിരക്ക്: സ്വയം പുതുക്കലോടെ പ്രതിമാസം $6.99 അല്ലെങ്കിൽ പ്രതിവർഷം $49.99. പ്രാദേശിക നിരക്ക്, ലഭ്യത, അന്തിമ നിബന്ധനകൾ App Store-ൽ കാണാം. Apple അക്കൗണ്ടിൽ നിയന്ത്രിക്കുകയോ റദ്ദാക്കുകയോ ചെയ്യൂ; ആപ്പിൽ വാങ്ങലുകൾ പുനഃസ്ഥാപിക്കൂ.
