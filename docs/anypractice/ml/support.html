ആപ്പ് പതിപ്പ്, iOS പതിപ്പ്, തിരഞ്ഞെടുത്ത AI കണക്ഷൻ, പിശക് സന്ദേശം എന്നിവ നൽകൂ. API കീകൾ, Apple പാസ്‌വേഡുകൾ, വാങ്ങലിന്റെ പ്രാമാണീകരണ വിവരങ്ങൾ, സ്വകാര്യ രേഖകൾ എന്നിവ അയയ്ക്കരുത്.

നിങ്ങളുടെ മെറ്റീരിയൽ

സാമഗ്രി ഇറക്കുമതി ചെയ്യുകയോ ഒട്ടിക്കുകയോ ചെയ്ത് പഠനരീതി തിരഞ്ഞെടുക്കൂ; AI കണക്ഷൻ പരിശോധിക്കൂ. സജീവമായ Pro ഇല്ലെങ്കിൽ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ സ്വന്തം API കീ വേണം. മറ്റൊരു സേവനദാതാവിനെ വ്യക്തമായി തിരഞ്ഞെടുക്കാത്തപക്ഷം Pro സ്ഥിരസ്ഥിതിയായി ഞങ്ങളുടെ സേവനം ഉപയോഗിക്കും. ഉപകരണവും ഉറവിടത്തിന്റെയും ചോദ്യങ്ങളുടെയും ഭാഷകളും പിന്തുണയ്ക്കുമ്പോൾ ഉറവിടാധിഷ്ഠിത ഫ്ലാഷ്‌കാർഡ് കരടുകൾക്കായി Apple Intelligence Pro-യിൽ മാത്രം ലഭ്യമാണ്. പാഠങ്ങൾ, സംഗ്രഹങ്ങൾ, ക്വിസുകൾ എന്നിവ സൃഷ്ടിക്കാൻ ക്ലൗഡ് കണക്ഷൻ വേണം. Pro കാലാവധി കഴിഞ്ഞാൽ Pro വഴിയുള്ള സൃഷ്ടിക്കൽ തടയും; Apple ലഭ്യമല്ലെങ്കിൽ തിരഞ്ഞെടുത്ത Apple വഴി തടയും. ആപ്പ് സേവനദാതാവിനെ സ്വയമേവ മാറ്റുകയില്ല. സൂക്ഷിച്ച പാഠങ്ങളും പരിശീലനവും ഓഫ്‌ലൈനിൽ പ്രവർത്തിക്കുന്നു.

ഫോട്ടോകളും PDF-കളും

വ്യക്തവും നല്ല വെളിച്ചമുള്ളതുമായ ഫോട്ടോ ഉപയോഗിച്ച് തിരിച്ചറിഞ്ഞ എഴുത്ത് പരിശോധിക്കൂ. Pro പാഠങ്ങൾക്ക് യഥാർത്ഥ ഫോട്ടോയോ തിരഞ്ഞെടുത്ത മുഴുവൻ PDF പേജുകളോ വ്യക്തമായി സ്ഥിരീകരിക്കാം; മുഴുവൻ പേജിൽ തിരഞ്ഞെടുക്കാത്ത എഴുത്തും ഉണ്ടാകാം. വ്യക്തിഗത ദാതാവിലൂടെയും ഉറവിട കാർഡുകളിലൂടെയുമുള്ള സൃഷ്ടിക്കൽ എഴുത്ത് മാത്രം ഉപയോഗിക്കുന്നു.

AnyPractice Pro — ശുപാർശ ചെയ്യുന്നത്

മികച്ച മോഡലുകൾ ഉപയോഗിച്ച് പാഠങ്ങൾ, വിശദീകരണങ്ങൾ, സംഗ്രഹങ്ങൾ, പരിശീലനങ്ങൾ എന്നിവ സൃഷ്ടിക്കുക.

Pro ക്ലൗഡ് സേവനം ഉപയോഗിക്കുമ്പോൾ: Pro-യിൽ ഓരോ UTC കലണ്ടർ മാസവും പരമാവധി 60 ആരംഭിച്ച സൃഷ്ടിക്കൽ അഭ്യർത്ഥനകളും UTC ദിവസത്തിൽ പരമാവധി 5-ഉം ഉൾപ്പെടുന്നു. സേവനത്തിന്റെ മൊത്തത്തിലുള്ള ഉപയോഗ, ബജറ്റ് പരിധികൾ നിങ്ങളുടെ വ്യക്തിഗത ക്വോട്ട തീരുന്നതിനുമുമ്പ് സൃഷ്ടിക്കൽ താൽക്കാലികമായി നിർത്തിയേക്കാം. ആരംഭിച്ച അഭ്യർത്ഥനകൾ പരാജയപ്പെട്ടാലും തടസ്സപ്പെട്ടാലും എണ്ണപ്പെടും. സൂക്ഷിച്ച സാമഗ്രി ഓഫ്‌ലൈനിൽ ലഭ്യമാണ്.

അമേരിക്കൻ നിരക്ക്: സ്വയം പുതുക്കലോടെ പ്രതിമാസം $6.99 അല്ലെങ്കിൽ പ്രതിവർഷം $49.99. പ്രാദേശിക നിരക്ക്, ലഭ്യത, അന്തിമ നിബന്ധനകൾ App Store-ൽ കാണാം. Apple അക്കൗണ്ടിൽ നിയന്ത്രിക്കുകയോ റദ്ദാക്കുകയോ ചെയ്യൂ; ആപ്പിൽ വാങ്ങലുകൾ പുനഃസ്ഥാപിക്കൂ.

സജീവമായ Pro ഇല്ലെങ്കിൽ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ സ്വന്തം API കീ വേണം. മറ്റൊരു സേവനദാതാവിനെ വ്യക്തമായി തിരഞ്ഞെടുക്കാത്തപക്ഷം Pro സ്ഥിരസ്ഥിതിയായി ഞങ്ങളുടെ സേവനം ഉപയോഗിക്കും. ഉപകരണവും ഉറവിടത്തിന്റെയും ചോദ്യങ്ങളുടെയും ഭാഷകളും പിന്തുണയ്ക്കുമ്പോൾ ഉറവിടാധിഷ്ഠിത ഫ്ലാഷ്‌കാർഡ് കരടുകൾക്കായി Apple Intelligence Pro-യിൽ മാത്രം ലഭ്യമാണ്. പാഠങ്ങൾ, സംഗ്രഹങ്ങൾ, ക്വിസുകൾ എന്നിവ സൃഷ്ടിക്കാൻ ക്ലൗഡ് കണക്ഷൻ വേണം. Pro കാലാവധി കഴിഞ്ഞാൽ Pro വഴിയുള്ള സൃഷ്ടിക്കൽ തടയും; Apple ലഭ്യമല്ലെങ്കിൽ തിരഞ്ഞെടുത്ത Apple വഴി തടയും. ആപ്പ് സേവനദാതാവിനെ സ്വയമേവ മാറ്റുകയില്ല. OpenAI, Anthropic, Gemini അല്ലെങ്കിൽ അനുയോജ്യമായ സേവനദാതാവിനൊപ്പം വ്യക്തിഗത API കീ ഉപയോഗിക്കൂ. API ഉപയോഗത്തിന് ദാതാവ് പ്രത്യേകം നിരക്ക് ഈടാക്കുന്നു.

സൃഷ്ടിച്ച ഉള്ളടക്കം റിപ്പോർട്ട് ചെയ്യുക

AI തെറ്റുകൾ വരുത്താം. ആപ്പിൽ സൃഷ്ടിച്ച പഠനസാമഗ്രികൾ തിരുത്താനോ ഇല്ലാതാക്കാനോ കഴിയും. ഹാനികരമായ ഉള്ളടക്കം റിപ്പോർട്ട് ചെയ്യാൻ സ്വകാര്യ വിവരങ്ങൾ ഉൾപ്പെടുത്താതെ പ്രശ്നം വിവരിക്കുക.

സംരക്ഷിച്ച ഡാറ്റ നീക്കം ചെയ്യുക

ഒരു ഡെക്ക് ഇല്ലാതാക്കിയാൽ, അതിന്റെ സംരക്ഷിച്ച ടെക്സ്റ്റ്, ഫോട്ടോയുടെയോ PDF-യുടെയോ പ്രാദേശിക പകർപ്പ്, സൃഷ്ടിച്ച മെറ്റീരിയൽ, പുരോഗതി എന്നിവ ഈ ആപ്പിൽനിന്ന് നീക്കം ചെയ്യും. അതേ മെറ്റീരിയൽ ഉപയോഗിക്കുന്ന മറ്റ് ഡെക്കുകൾ അവയുടെ പകർപ്പുകൾ നിലനിർത്തും. «കണക്ഷൻ നീക്കം ചെയ്യുക» സംരക്ഷിച്ച വ്യക്തിഗത കീ ഇല്ലാതാക്കും. ഈ ആപ്പിനു പുറത്തുള്ള ഫയലുകൾ, ബാക്കപ്പുകൾ, സേവനദാതാവിന്റെ കൈവശമുള്ള ഡാറ്റ എന്നിവ വേറെയാണ്.
