പുതുക്കിയത്: 20 നവംബർ 2026

സ്വകാര്യതാ നയം

നിങ്ങളുടെ സാമഗ്രി. നിങ്ങളുടെ തിരഞ്ഞെടുപ്പ്.

ഈ പേജിൽ
പ്രാദേശിക ലൈബ്രറിഫോട്ടോകളും PDF-കളുംAI സേവനദാതാക്കൾApple IntelligenceAnyPractice Proസംരക്ഷിച്ച ഡാറ്റ നീക്കം ചെയ്യുകസേവനരേഖകളും ദാതാക്കളുടെ വിവരസംഭരണവുംസഹായം

പ്രാദേശിക ലൈബ്രറി

വേർതിരിച്ചെടുത്ത പഠനവാചകം, പാഠങ്ങൾ, കാർഡുകൾ, പുരോഗതി എന്നിവ നിങ്ങളുടെ ഉപകരണത്തിലെ ഈ ആപ്പിൽ സംരക്ഷിക്കുന്നു. ആപ്പ് AnyPractice അക്കൗണ്ട് സൃഷ്ടിക്കുകയോ സ്വന്തമായ ക്ലൗഡ് സിങ്ക് നൽകുകയോ ചെയ്യുന്നില്ല. ഉപകരണത്തിന്റെ ബാക്കപ്പുകളിൽ ആപ്പിന്റെ പ്രാദേശിക ഡാറ്റ ഉൾപ്പെട്ടേക്കാം.

ഫോട്ടോകളും PDF-കളും

ടെക്സ്റ്റ് തിരിച്ചറിയൽ നിങ്ങളുടെ ഉപകരണത്തിലാണ് നടക്കുന്നത്. ഇറക്കുമതി ചെയ്ത ഫോട്ടോകളും PDF-കളും നിങ്ങളുടെ മെറ്റീരിയലിനൊപ്പം പ്രാദേശികമായി സംരക്ഷിക്കപ്പെടുന്നു. Pro പാഠങ്ങൾക്കായി, അവലോകനം ചെയ്ത് സ്ഥിരീകരിച്ച ശേഷം ഫോട്ടോയോ തിരഞ്ഞെടുത്ത പൂർണ്ണ PDF പേജുകളോ OpenAI-ലേക്ക് അയയ്ക്കാം. ടെക്സ്റ്റ് മാത്രമുള്ള മോഡുകൾ അവലോകനം ചെയ്ത ടെക്സ്റ്റ് മാത്രമേ അയയ്ക്കൂ.

AI സേവനദാതാക്കൾ

സജീവമായ Pro ഇല്ലെങ്കിൽ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ സ്വന്തം API കീ വേണം. മറ്റൊരു സേവനദാതാവിനെ വ്യക്തമായി തിരഞ്ഞെടുക്കാത്തപക്ഷം Pro സ്ഥിരസ്ഥിതിയായി ഞങ്ങളുടെ സേവനം ഉപയോഗിക്കും. ഉപകരണവും ഉറവിടത്തിന്റെയും ചോദ്യങ്ങളുടെയും ഭാഷകളും പിന്തുണയ്ക്കുമ്പോൾ ഉറവിടാധിഷ്ഠിത ഫ്ലാഷ്‌കാർഡ് കരടുകൾക്കായി Apple Intelligence Pro-യിൽ മാത്രം ലഭ്യമാണ്. പാഠങ്ങൾ, സംഗ്രഹങ്ങൾ, ക്വിസുകൾ എന്നിവ സൃഷ്ടിക്കാൻ ക്ലൗഡ് കണക്ഷൻ വേണം. Pro കാലാവധി കഴിഞ്ഞാൽ Pro വഴിയുള്ള സൃഷ്ടിക്കൽ തടയും; Apple ലഭ്യമല്ലെങ്കിൽ തിരഞ്ഞെടുത്ത Apple വഴി തടയും. ആപ്പ് സേവനദാതാവിനെ സ്വയമേവ മാറ്റുകയില്ല. OpenAI, Anthropic, Gemini അല്ലെങ്കിൽ അനുയോജ്യമായ സേവനദാതാവിനൊപ്പം വ്യക്തിഗത API കീ ഉപയോഗിക്കൂ. API ഉപയോഗത്തിന് ദാതാവ് പ്രത്യേകം നിരക്ക് ഈടാക്കുന്നു. നിങ്ങളുടെ API കീ ഉപയോഗിക്കുമ്പോൾ, തിരഞ്ഞെടുത്ത ഭാഗങ്ങളും സൃഷ്ടിക്കാനുള്ള നിർദ്ദേശങ്ങളും മാത്രമാണ് നിങ്ങൾ സ്ഥിരീകരിക്കുന്ന സേവനദാതാവിനും മോഡലിനും നേരിട്ട് അയയ്ക്കുന്നത്. ഈ ഉപകരണത്തിന്റെ Keychain-ൽ നിങ്ങളുടെ കീ സൂക്ഷിക്കുന്നു. സേവനദാതാവ് സ്വന്തം നിബന്ധനകൾ പ്രകാരം അഭ്യർത്ഥനകൾ സൂക്ഷിച്ചേക്കാം. ആ സേവനദാതാവിന്റെ പക്കൽ ഇതിനകം ഉള്ള പകർപ്പുകൾ ഇല്ലാതാക്കാൻ AnyPractice-ന് കഴിയില്ല.

Apple Intelligence

ഈ ഓപ്ഷന് സജീവമായ Pro സബ്‌സ്‌ക്രിപ്ഷൻ ആവശ്യമാണ്. Apple Intelligence പിന്തുണയ്ക്കുന്ന ഉപകരണങ്ങളിൽ സ്രോതസ്സിനെ അടിസ്ഥാനമാക്കിയുള്ള ഫ്ലാഷ്കാർഡുകൾ സൃഷ്ടിക്കുന്നു. സൃഷ്ടിക്കലും പിന്തുണയ്ക്കുന്ന വിവർത്തനവും ഉപകരണത്തിൽത്തന്നെ നടക്കുന്നു; ഭാഷാ വിഭവങ്ങൾ ഡൗൺലോഡ് ചെയ്യേണ്ടിവരാം.

AnyPractice Pro

Pro ക്ലൗഡ് സേവനം ഉപയോഗിക്കുമ്പോൾ: Pro-യിൽ തിരഞ്ഞെടുത്ത ടെക്സ്റ്റും സ്ഥിരീകരിച്ച മൂല പേജുകളും Vercel-ലുള്ള AnyPractice വഴി OpenAI-ലേക്ക് പോകുന്നു. സർവറിൽ ഫയൽ ലൈബ്രറി സൃഷ്ടിക്കാതെ, ആ അഭ്യർത്ഥനയ്ക്കായി മൂല ഫയലുകൾ പ്രോസസ് ചെയ്യപ്പെടുന്നു. Apple പണമിടപാടുകൾ കൈകാര്യം ചെയ്യുന്നു; സർവർ നിങ്ങളുടെ സബ്സ്ക്രിപ്ഷൻ പരിശോധിക്കുകയും തിരിച്ചറിയൽ വിവരങ്ങളും ഉപയോഗത്തിന്റെ എണ്ണവും സൂക്ഷിക്കുകയും ചെയ്യുന്നു. സേവനദാതാക്കളും ഹോസ്റ്റിംഗ് സേവനങ്ങളും അവരുടെ സ്വന്തം നയങ്ങൾ അനുസരിച്ച് ഡാറ്റ കൈകാര്യം ചെയ്യുന്നു.

സംരക്ഷിച്ച ഡാറ്റ നീക്കം ചെയ്യുക

ഒരു ഡെക്ക് ഇല്ലാതാക്കിയാൽ, അതിന്റെ സംരക്ഷിച്ച ടെക്സ്റ്റ്, ഫോട്ടോയുടെയോ PDF-യുടെയോ പ്രാദേശിക പകർപ്പ്, സൃഷ്ടിച്ച മെറ്റീരിയൽ, പുരോഗതി എന്നിവ ഈ ആപ്പിൽനിന്ന് നീക്കം ചെയ്യും. അതേ മെറ്റീരിയൽ ഉപയോഗിക്കുന്ന മറ്റ് ഡെക്കുകൾ അവയുടെ പകർപ്പുകൾ നിലനിർത്തും. «കണക്ഷൻ നീക്കം ചെയ്യുക» സംരക്ഷിച്ച വ്യക്തിഗത കീ ഇല്ലാതാക്കും. ഈ ആപ്പിനു പുറത്തുള്ള ഫയലുകൾ, ബാക്കപ്പുകൾ, സേവനദാതാവിന്റെ കൈവശമുള്ള ഡാറ്റ എന്നിവ വേറെയാണ്.

സേവനരേഖകളും ദാതാക്കളുടെ വിവരസംഭരണവും

Pro ക്ലൗഡ് സേവനം ഉപയോഗിക്കുമ്പോൾ: Pro സ്ഥിരീകരിച്ച സാമഗ്രി Vercel വഴി OpenAI-ലേക്ക് കൈമാറുന്നു. സെർവറിൽ പഠനഫയലുകളുടെ ലൈബ്രറി ഞങ്ങൾ സൂക്ഷിക്കുകയോ പഠനവിവരങ്ങൾ മനഃപൂർവം ലോഗ് ചെയ്യുകയോ ചെയ്യുന്നില്ല. ഇത് ശൂന്യസംഭരണം എന്നല്ല: ദാതാക്കളുടെയും അടിസ്ഥാനസൗകര്യത്തിന്റെയും നയങ്ങൾ തുടർന്നും ബാധകമാണ്. OpenAI അഭ്യർത്ഥനകൾ store:false ഉപയോഗിക്കുന്നു; സാധാരണ ദുരുപയോഗനിരീക്ഷണത്തിന്റെ ഉള്ളടക്കം നിയമ/സുരക്ഷാ ഒഴിവുകളോടെ 30 ദിവസം വരെ സൂക്ഷിക്കാം. വരിക്കാരുടെ പ്രവേശനം, സുരക്ഷ, പരിധികൾ എന്നിവയ്ക്കായി ഒപ്പിട്ട Apple ഇടപാടുകൾ, സ്ഥിരമായ ഹാഷ് ചെയ്ത സബ്സ്ക്രിപ്ഷൻ/അഭ്യർത്ഥന തിരിച്ചറിയൽ വിവരങ്ങൾ, UTC കൗണ്ടറുകൾ എന്നിവ ഉപയോഗിക്കുന്നു. ഇവ അജ്ഞാതമല്ല. ദിവസകൗണ്ടറുകൾ അവസാന പുതുക്കലിന് 3 ദിവസത്തിന് ശേഷം, മാസകൗണ്ടറുകൾ 35 ദിവസത്തിന് ശേഷം കാലഹരണപ്പെടും; ആവർത്തിച്ച അഭ്യർത്ഥന കണ്ടെത്താനുള്ള ഹാഷുകൾ സ്വയം കാലഹരണപ്പെടില്ല. പ്രാദേശിക കാർഡ് ശേഖരം ഇല്ലാതാക്കുന്നത് ഈ രേഖകൾ, ദാതാക്കളുടെ രേഖകൾ, ഓപ്പറേറ്റിങ് സിസ്റ്റം ബാക്കപ്പുകൾ, പിന്തുണയുമായുള്ള കത്തിടപാടുകൾ എന്നിവ ഇല്ലാതാക്കുന്നില്ല. സേവനവിവര അഭ്യർത്ഥനകൾക്ക് ബന്ധപ്പെടൂ; രഹസ്യ കീ അല്ലെങ്കിൽ പാസ്‌വേഡ് ഒരിക്കലും അയയ്ക്കരുത്.

സഹായം

പഠിതാവിന്റെ അക്കൗണ്ട്, പരസ്യ SDK, ആപ്പുകൾക്കിടയിലെ ട്രാക്കിങ് എന്നിവയില്ല. വെബ്‌സൈറ്റ് വിശകലന കുക്കികളോ പരസ്യ സ്ക്രിപ്റ്റുകളോ ഉപയോഗിക്കുന്നില്ല. GitHub Pages സാധാരണ ഹോസ്റ്റിങ്/നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനകൾ തുടർന്നും കൈകാര്യം ചെയ്യുന്നു. പിന്തുണയ്ക്ക് അയക്കുന്ന ഇമെയിലും നിങ്ങൾ തിരഞ്ഞെടുത്ത് നൽകുന്ന വിവരങ്ങളും മറുപടിക്കും പ്രശ്നപരിശോധനയ്ക്കും ഉപയോഗിക്കുന്നു. പണമടയ്ക്കൽ Apple കൈകാര്യം ചെയ്യുന്നു; കാർഡ് വിവരങ്ങളോ Apple പാസ്‌വേഡുകളോ ഞങ്ങൾക്ക് ലഭിക്കുന്നില്ല. AnyPractice മുതിർന്നവർ, മാതാപിതാക്കൾ, അധ്യാപകർ എന്നിവർക്കുള്ളതാണ്.
