આ પાનાં પર
સ્થાનિક લાઇબ્રેરીફોટા અને PDFAI પ્રદાતાઓApple IntelligenceAnyPractice Proસાચવેલો ડેટા દૂર કરોસેવાના રેકોર્ડ અને પ્રદાતાઓ દ્વારા ડેટાનો સંગ્રહસહાય

સ્થાનિક લાઇબ્રેરી

કાઢેલું અભ્યાસનું લખાણ, પાઠ, કાર્ડ અને પ્રગતિ તમારા ઉપકરણ પર આ ઍપમાં સચવાય છે. ઍપ AnyPractice ખાતું બનાવતી નથી કે પોતાની ક્લાઉડ સમન્વય સુવિધા આપતી નથી. ઉપકરણનાં બૅકઅપમાં ઍપનો સ્થાનિક ડેટા હોઈ શકે છે.

ફોટા અને PDF

ટેક્સ્ટ ઓળખવાની પ્રક્રિયા તમારા ઉપકરણ પર ચાલે છે. આયાત કરેલા ફોટા અને PDF પણ તમારી સામગ્રી સાથે સ્થાનિક રીતે સાચવાય છે. Pro પાઠ માટે, સમીક્ષા અને પુષ્ટિ કર્યા પછી તમે ફોટો અથવા પસંદ કરેલાં સંપૂર્ણ PDF પાનાં OpenAIને મોકલી શકો છો. માત્ર ટેક્સ્ટવાળા મોડ ફક્ત સમીક્ષા કરેલું ટેક્સ્ટ મોકલે છે.

AI પ્રદાતાઓ

સક્રિય Pro વિના જનરેશન માટે તમારી પોતાની API કી જરૂરી છે. તમે સ્પષ્ટ રીતે બીજો પ્રદાતા ન પસંદ કરો ત્યાં સુધી Pro ડિફૉલ્ટ રૂપે અમારી સેવા વાપરે છે. ઉપકરણ તથા સ્ત્રોત અને પ્રશ્નોની બંને ભાષાઓ સમર્થિત હોય ત્યારે સ્ત્રોત આધારિત ફ્લૅશકાર્ડના ડ્રાફ્ટ માટે Apple Intelligence માત્ર Pro સાથે ઉપલબ્ધ છે. પાઠ, સારાંશ અને ક્વિઝ બનાવવા ક્લાઉડ જોડાણ જરૂરી છે. Pro સમાપ્ત થતાં Pro જનરેશન અટકે છે; Apple ઉપલબ્ધ ન હોય તો પસંદ કરેલો Apple માર્ગ અટકે છે. ઍપ પ્રદાતા આપમેળે બદલતી નથી. OpenAI, Anthropic, Gemini અથવા સુસંગત પ્રદાતા સાથે વ્યક્તિગત API કી વાપરો. પ્રદાતા API વપરાશનું બિલ અલગથી લે છે. તમારી API કી સાથે, માત્ર પસંદ કરેલા અંશો અને સામગ્રી બનાવવાની સૂચનાઓ તમે પુષ્ટિ કરેલા પ્રદાતા અને મૉડલને સીધી મોકલવામાં આવે છે. તમારી કી આ ઉપકરણના Keychainમાં સચવાય છે. પ્રદાતા તેની શરતો મુજબ વિનંતીઓ રાખી શકે છે. તે પ્રદાતા પાસે પહેલેથી રહેલી નકલો AnyPractice કાઢી શકતું નથી.

Apple Intelligence

આ વિકલ્પ માટે સક્રિય Pro સબ્સ્ક્રિપ્શન જરૂરી છે. Apple Intelligence સમર્થિત ઉપકરણો પર સ્રોત-આધારિત ફ્લેશકાર્ડ બનાવે છે. સામગ્રી બનાવવાનું અને સમર્થિત અનુવાદ સ્થાનિક રીતે થાય છે; ભાષાના સંસાધનો ડાઉનલોડ કરવા પડી શકે છે.

AnyPractice Pro

Pro ક્લાઉડ સેવાનો ઉપયોગ કરતી વખતે: Proમાં પસંદ કરેલું ટેક્સ્ટ અને પુષ્ટિ કરેલાં મૂળ પાનાં Vercel પરના AnyPractice દ્વારા OpenAI સુધી જાય છે. સર્વર પર ફાઇલ લાઇબ્રેરી બનાવ્યા વિના, મૂળ ફાઇલો તે વિનંતી માટે પ્રોસેસ થાય છે. Apple ચુકવણીની પ્રક્રિયા કરે છે; સર્વર તમારું સબ્સ્ક્રિપ્શન ચકાસે છે અને ઓળખકર્તા તથા વપરાશની ગણતરી સાચવે છે. પ્રદાતા અને હોસ્ટિંગ સેવાઓ તેમની પોતાની નીતિઓ અનુસાર ડેટા સંભાળે છે.

સાચવેલો ડેટા દૂર કરો

ડેક કાઢી નાખવાથી આ ઍપમાંથી તેનું સાચવેલું ટેક્સ્ટ, ફોટા અથવા PDFની સ્થાનિક નકલ, બનાવેલી સામગ્રી અને પ્રગતિ દૂર થશે. એ જ સામગ્રી વાપરતા અન્ય ડેક તેમની નકલો રાખશે. «કનેક્શન દૂર કરો» સાચવેલી વ્યક્તિગત કી કાઢી નાખે છે. આ ઍપની બહારની ફાઇલો, બૅકઅપ અને પ્રદાતા પાસેનો ડેટા અલગ છે.

સેવાના રેકોર્ડ અને પ્રદાતાઓ દ્વારા ડેટાનો સંગ્રહ

Pro ક્લાઉડ સેવાનો ઉપયોગ કરતી વખતે: Pro પુષ્ટિ કરેલી સામગ્રી Vercel મારફતે OpenAIને મોકલે છે. અમે સર્વર પર અભ્યાસ ફાઇલોની લાઇબ્રેરી રાખતા નથી કે ઇરાદાપૂર્વક અભ્યાસ સામગ્રી લૉગ કરતા નથી. આનો અર્થ શૂન્ય સંગ્રહ નથી: પ્રદાતા અને માળખાકીય સુવિધાની નીતિઓ લાગુ રહે છે. OpenAI વિનંતીઓ store:false વાપરે છે; સામાન્ય દુરુપયોગ દેખરેખની સામગ્રી કાયદાકીય/સલામતી અપવાદો સાથે 30 દિવસ સુધી રહી શકે છે. સબ્સ્ક્રિપ્શન પ્રવેશ, સલામતી અને મર્યાદા માટે સહી કરેલા Apple વ્યવહારો, સ્થિર હૅશ કરેલા સબ્સ્ક્રિપ્શન/વિનંતી ઓળખકર્તા અને UTC ગણકો વપરાય છે. આ ઓળખકર્તાઓ અનામી નથી. દૈનિક ગણકો છેલ્લા સુધારાના 3 દિવસ પછી અને માસિક ગણકો 35 દિવસ પછી સમાપ્ત થાય છે; ડુપ્લિકેટ વિનંતી ઓળખવાના હૅશ આપમેળે સમાપ્ત થતા નથી. સ્થાનિક ડેક કાઢવાથી આ રેકોર્ડ, પ્રદાતાના રેકોર્ડ, ઑપરેટિંગ સિસ્ટમ બૅકઅપ કે સપોર્ટ પત્રવ્યવહાર મટતો નથી. સેવાના ડેટાની વિનંતીઓ માટે અમારો સંપર્ક કરો; ક્યારેય ગુપ્ત કી કે પાસવર્ડ ન મોકલો.

સહાય

શીખનારનું ખાતું, જાહેરાત SDK કે એપ વચ્ચે ટ્રૅકિંગ નથી. વેબસાઇટ વિશ્લેષણ કુકી કે જાહેરાત સ્ક્રિપ્ટ વાપરતી નથી. GitHub Pages હજી સામાન્ય હોસ્ટિંગ/નેટવર્ક વિનંતીઓ સંભાળે છે. સપોર્ટને મોકલેલો ઇમેઇલ અને તમારી પસંદગીની માહિતી જવાબ આપવા અને સમસ્યા તપાસવા વપરાય છે. ચૂકવણી Apple સંભાળે છે; અમને કાર્ડની વિગતો કે Apple પાસવર્ડ મળતા નથી.
