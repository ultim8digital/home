એપનું સંસ્કરણ, iOS સંસ્કરણ, પસંદ કરેલું AI જોડાણ અને ભૂલનો સંદેશ આપો. API કી, Apple પાસવર્ડ, ખરીદીના પ્રમાણીકરણની વિગતો કે ખાનગી દસ્તાવેજો ન મોકલો.

તમારી સામગ્રી

સામગ્રી આયાત અથવા પેસ્ટ કરો, શીખવાની રીત પસંદ કરો અને AI જોડાણ તપાસો. સક્રિય Pro વિના જનરેશન માટે તમારી પોતાની API કી જરૂરી છે. તમે સ્પષ્ટ રીતે બીજો પ્રદાતા ન પસંદ કરો ત્યાં સુધી Pro ડિફૉલ્ટ રૂપે અમારી સેવા વાપરે છે. ઉપકરણ તથા સ્ત્રોત અને પ્રશ્નોની બંને ભાષાઓ સમર્થિત હોય ત્યારે સ્ત્રોત આધારિત ફ્લૅશકાર્ડના ડ્રાફ્ટ માટે Apple Intelligence માત્ર Pro સાથે ઉપલબ્ધ છે. પાઠ, સારાંશ અને ક્વિઝ બનાવવા ક્લાઉડ જોડાણ જરૂરી છે. Pro સમાપ્ત થતાં Pro જનરેશન અટકે છે; Apple ઉપલબ્ધ ન હોય તો પસંદ કરેલો Apple માર્ગ અટકે છે. ઍપ પ્રદાતા આપમેળે બદલતી નથી. સાચવેલા પાઠ અને અભ્યાસ ઑફલાઇન ચાલે છે.

ફોટા અને PDF

સ્પષ્ટ, સારી રોશનીવાળો ફોટો વાપરો અને ઓળખાયેલું લખાણ તપાસો. Pro પાઠ માટે મૂળ ફોટો અથવા પસંદ કરેલાં આખાં PDF પાનાંની સ્પષ્ટ પુષ્ટિ કરી શકો છો; આખા પાનામાં પસંદ ન કરેલું લખાણ પણ હોઈ શકે છે. વ્યક્તિગત પ્રદાતા અને સ્ત્રોત-કાર્ડ જનરેશન ફક્ત લખાણ વાપરે છે.

AnyPractice Pro — ભલામણ કરેલ

શ્રેષ્ઠ મોડેલો વડે પાઠ, સમજૂતીઓ, સારાંશ અને અભ્યાસ બનાવો.

Pro ક્લાઉડ સેવાનો ઉપયોગ કરતી વખતે: Proમાં દરેક UTC કૅલેન્ડર મહિને વધુમાં વધુ 60 શરૂ કરેલી જનરેશન વિનંતીઓ અને UTC દિવસે વધુમાં વધુ 5 સામેલ છે. સેવાના એકંદર ઉપયોગ અને બજેટની મર્યાદાઓને કારણે તમારો વ્યક્તિગત ક્વોટા પૂરો થાય તે પહેલાં જનરેશન થોભી શકે છે. શરૂ થયેલી વિનંતીઓ નિષ્ફળ જાય કે અટકે તો પણ ગણાય છે. સાચવેલી સામગ્રી ઑફલાઇન ઉપલબ્ધ રહે છે.

અમેરિકાની કિંમત: આપમેળે નવીનીકરણ સાથે મહિને $6.99 અથવા વર્ષે $49.99. સ્થાનિક કિંમત, ઉપલબ્ધતા અને અંતિમ શરતો App Storeમાં દર્શાવાય છે. Apple ખાતામાં સંચાલન કે રદ કરો; એપમાં ખરીદી પુનઃસ્થાપિત કરો.

સક્રિય Pro વિના જનરેશન માટે તમારી પોતાની API કી જરૂરી છે. તમે સ્પષ્ટ રીતે બીજો પ્રદાતા ન પસંદ કરો ત્યાં સુધી Pro ડિફૉલ્ટ રૂપે અમારી સેવા વાપરે છે. ઉપકરણ તથા સ્ત્રોત અને પ્રશ્નોની બંને ભાષાઓ સમર્થિત હોય ત્યારે સ્ત્રોત આધારિત ફ્લૅશકાર્ડના ડ્રાફ્ટ માટે Apple Intelligence માત્ર Pro સાથે ઉપલબ્ધ છે. પાઠ, સારાંશ અને ક્વિઝ બનાવવા ક્લાઉડ જોડાણ જરૂરી છે. Pro સમાપ્ત થતાં Pro જનરેશન અટકે છે; Apple ઉપલબ્ધ ન હોય તો પસંદ કરેલો Apple માર્ગ અટકે છે. ઍપ પ્રદાતા આપમેળે બદલતી નથી. OpenAI, Anthropic, Gemini અથવા સુસંગત પ્રદાતા સાથે વ્યક્તિગત API કી વાપરો. પ્રદાતા API વપરાશનું બિલ અલગથી લે છે.

બનાવેલી સામગ્રીની જાણ કરો

AI ભૂલો કરી શકે છે. તમે ઍપમાં બનાવેલી સામગ્રીને સંપાદિત અથવા કાઢી શકો છો. હાનિકારક સામગ્રીની જાણ કરવા માટે ખાનગી માહિતી આપ્યા વિના સમસ્યા વર્ણવો.

સાચવેલો ડેટા દૂર કરો

ડેક કાઢી નાખવાથી આ ઍપમાંથી તેનું સાચવેલું ટેક્સ્ટ, ફોટા અથવા PDFની સ્થાનિક નકલ, બનાવેલી સામગ્રી અને પ્રગતિ દૂર થશે. એ જ સામગ્રી વાપરતા અન્ય ડેક તેમની નકલો રાખશે. «કનેક્શન દૂર કરો» સાચવેલી વ્યક્તિગત કી કાઢી નાખે છે. આ ઍપની બહારની ફાઇલો, બૅકઅપ અને પ્રદાતા પાસેનો ડેટા અલગ છે.
