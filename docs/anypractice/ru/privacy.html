Локальная библиотека и распознавание

Учётная запись ученика в AnyPractice не нужна. Колоды, уроки, изменения, прогресс и сохранённые оригиналы фото/PDF хранятся в приложении на устройстве. Распознавание текста выполняется на устройстве. Резервные копии, которыми управляет операционная система, могут включать данные приложения. С активной подпиской Pro можно явно выбрать Apple Intelligence для черновиков карточек по источнику, если поддерживаются устройство, язык материала и язык вопросов. Генерация выполняется локально. Для генерации уроков, сводок и тестов нужно облачное подключение.

Что получает провайдер ИИ

Без активной подписки Pro для генерации нужен свой API-ключ. С Pro по умолчанию используется наш сервис, если вы явно не выбрали другого провайдера. Apple Intelligence доступен только с Pro для черновиков карточек по источнику, если поддерживаются устройство, язык материала и язык вопросов. Для генерации уроков, сводок и тестов нужно облачное подключение. Истечение Pro блокирует генерацию через Pro; недоступность Apple блокирует выбранный режим Apple. Приложение не переключает провайдеров автоматически. Используйте личный API-ключ OpenAI, Anthropic, Gemini или совместимого провайдера. Использование API оплачивается отдельно по тарифам выбранного провайдера.

Облачная генерация передаёт материал, который вы проверили и подтвердили. Текст может включать названия документов, выбранные отрывки, ссылки на страницы, язык и настройки обучения, необходимые для запроса. Осторожно обращайтесь с личными, защищёнными авторским правом и чувствительными материалами. Передавайте только то, что имеете право использовать.

При работе с личным провайдером оригиналы изображений и PDF через наш сервис Pro не отправляются. Действуют условия, оплата и правила хранения вашего провайдера.

Полная страница может содержать отрывки, которые вы не выбирали как текст.

Обработка и хранение в Pro

Наш API не использует базу учебных материалов и намеренно не записывает их в журналы приложения. Это не означает отсутствие хранения: инфраструктурные провайдеры и OpenAI обрабатывают запросы по своим правилам. Запросы к OpenAI API используют store: false. Стандартные журналы OpenAI для контроля злоупотреблений могут хранить содержимое до 30 дней с указанными правовыми исключениями и исключениями безопасности; могут действовать и другие правила провайдера. Мы не обещаем режим Zero Data Retention. Подробнее: правила обработки данных OpenAI API.

Для доступа по подписке, безопасности, лимитов и защиты от повторных запросов сервис обрабатывает подписанные сведения о транзакциях Apple, продукте и среде, устойчивый хешированный идентификатор подписки, хеши запросов и счётчики использования по UTC. Хеширование не делает устойчивый идентификатор анонимным. Суточные счётчики истекают через 3 дня после последнего обновления, месячные — через 35 дней; доступная квота сбрасывается по дате и календарному месяцу UTC. Хеши для предотвращения повторных запросов автоматически не истекают. Журналы сервиса и инфраструктуры могут содержать технические сведения о запросах, ошибках и соединениях. Удаление колоды не означает удаления таких записей.

Покупки и поддержка

Оплату обрабатывает Apple. Мы не получаем данные платёжной карты или пароль Apple. Проверка покупки нужна для предоставления подписки и соблюдения лимитов. При обращении в поддержку или отправке жалобы мы получаем ваш email и сведения, которые вы отправляете, и используем их для ответа, расследования и работы сервиса. Для поддержки не требуются личные учебные документы и секреты API.

Реклама и отслеживание

В приложении нет рекламных SDK или SDK межприложенческого отслеживания. Мы не используем учебные материалы для рекламы. На этом сайте нет аналитических cookie или сторонних рекламных скриптов; GitHub Pages обрабатывает обычные запросы к хостингу и сетевые сведения по собственным правилам.

Удаление и ваш выбор

Удаление колоды удаляет её локальные материалы, сохранённые оригиналы и прогресс. Другие копии колод, резервные копии, переписка с поддержкой и данные провайдера существуют отдельно. Удаление API-подключения удаляет сохранённый ключ из Keychain приложения. Отмена подписки сама по себе не удаляет данные. Мы не можем удалённо стереть библиотеку на вашем устройстве. По вопросам доступа, исправления и удаления данных, обработанных нашим сервисом, напишите нам; для проверки запроса могут понадобиться дополнительные сведения, но не секретный ключ или пароль. Удаление может быть ограничено правилами провайдера, требованиями закона и записями безопасности.

Аудитория и изменения

AnyPractice предназначен для взрослых, родителей и преподавателей. Это не детский аккаунт и не общедоступная социальная сеть. ИИ может ошибаться; проверяйте ответы перед использованием. При изменении сервиса мы можем обновить эту политику и дату выше.
