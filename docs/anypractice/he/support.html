ציינו גרסת אפליקציה, גרסת iOS, חיבור הבינה המלאכותית שנבחר והודעת השגיאה. אל תשלחו מפתחות API, סיסמאות Apple, פרטי אימות רכישה או מסמכים פרטיים.

החומר שלכם

ייבאו או הדביקו חומר, בחרו מצב לימוד ובדקו את חיבור הבינה המלאכותית. ללא Pro פעיל, יצירת תוכן דורשת מפתח API משלכם. Pro משתמש בשירות שלנו כברירת מחדל, אלא אם בחרתם במפורש ספק אחר. Apple Intelligence זמין רק עם Pro לטיוטות כרטיסיות מבוססות מקור, כאשר המכשיר וגם שפות המקור והשאלות נתמכים. יצירת שיעורים, סיכומים ושאלונים דורשת חיבור ענן. פקיעת Pro חוסמת יצירה דרך Pro; אי־זמינות של Apple חוסמת את מסלול Apple שנבחר. האפליקציה אינה מחליפה ספק אוטומטית. שיעורים ותרגול שנשמרו עובדים ללא חיבור.

תמונות וקובצי PDF

השתמשו בתמונה חדה ומוארת היטב ובדקו את הטקסט שזוהה. לשיעורי Pro אפשר לאשר במפורש תמונה מקורית או עמודי PDF נבחרים במלואם; עמוד שלם עשוי לכלול טקסט שלא נבחר. יצירה דרך ספק אישי וכרטיסיות מקור משתמשות בטקסט בלבד.

AnyPractice Pro — מומלץ

צרו שיעורים, הסברים, סיכומים ותרגולים בעזרת המודלים הטובים ביותר.

בעת שימוש בשירות הענן של Pro: Pro כולל עד 60 בקשות יצירה שהחלו בכל חודש קלנדרי לפי UTC, ולכל היותר 5 ביום UTC. מגבלות השימוש והתקציב של השירות כולו עשויות להשהות את היצירה לפני ניצול המכסה האישית שלך. בקשות שהחלו נספרות גם אם נכשלו או הופסקו. חומר שנשמר נשאר זמין ללא חיבור.

מחירים בארה״ב: 6.99 דולר לחודש או 49.99 דולר לשנה, בחידוש אוטומטי. המחיר המקומי, הזמינות והתנאים הסופיים מוצגים ב-App Store. נהלו או בטלו בחשבון Apple; שחזרו רכישות באפליקציה.

ללא Pro פעיל, יצירת תוכן דורשת מפתח API משלכם. Pro משתמש בשירות שלנו כברירת מחדל, אלא אם בחרתם במפורש ספק אחר. דיווח על תוכן שנוצר

בינה מלאכותית עלולה לטעות. אפשר לערוך או למחוק חומר שנוצר בתוך האפליקציה. כדי לדווח על תוכן מזיק, יש לתאר את הבעיה בלי לכלול מידע פרטי.

הסרת נתונים שמורים

מחיקת חפיסה מסירה מהאפליקציה את הטקסט השמור שלה, את העותק המקומי של התמונה או ה-PDF, את החומרים שנוצרו ואת ההתקדמות. חפיסות אחרות המשתמשות באותו חומר שומרות על העותקים שלהן. הסרת חיבור מוחקת את המפתח האישי השמור. קבצים מחוץ לאפליקציה, גיבויים ונתונים אצל הספק מנוהלים בנפרד.
