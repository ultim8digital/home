隱私權政策

你的資料。你的選擇。

AnyPractice · Oleg Korunov / ULTIMATE DIGITAL · ultim8digital@gmail.com

本機資料庫

擷取的學習文字、課程、卡片和進度會儲存在你裝置上的這個 App 中。App 不會建立 AnyPractice 帳號，也不提供自有的雲端同步服務。裝置備份可能包含 App 的本機資料。

照片與 PDF

文字辨識在你的裝置上執行。匯入的照片和 PDF 也會連同學習資料儲存在本機。使用 Pro 課程時，你可以在檢查並確認後，將照片或所選的完整 PDF 頁面傳送給 OpenAI。純文字模式僅傳送檢查過的文字。

AI 供應商

沒有有效的 Pro 訂閱時，產生內容需要使用自己的 API 金鑰。除非你明確選擇其他供應商，否則 Pro 預設使用我們的服務。只有在裝置以及來源和問題的兩種語言均受支援時，Pro 使用者才能選擇 Apple Intelligence 產生以來源為基礎的記憶卡草稿。產生課程、摘要和測驗需要雲端連線。Pro 到期會阻止透過 Pro 產生；Apple 無法使用時會阻止所選的 Apple 路徑。App 不會自動切換供應商。 使用個人 API 金鑰連接 OpenAI、Anthropic、Gemini 或相容供應商。API 使用費由供應商另外收取。 使用自己的 API 金鑰時，只有選取的段落和內容產生指示會直接傳送至你確認的供應商和模型。金鑰儲存在此裝置的 Keychain 中。供應商可能會依照自身條款保留要求。AnyPractice 無法刪除該供應商已持有的副本。

Apple 智慧

此選項需要有效的 Pro 訂閱。 Apple Intelligence 可在支援的裝置上根據原始資料建立學習卡片。內容產生和支援的翻譯都在裝置上執行；可能需要下載語言資源。

AnyPractice Pro

使用 Pro 雲端服務時： 使用 Pro 時，所選文字和你確認傳送的原始頁面會透過 Vercel 上的 AnyPractice 傳送至 OpenAI。原始檔案僅為該請求進行處理，伺服器不設檔案庫。Apple 負責處理付款；伺服器驗證你的訂閱，並儲存識別碼和用量計數。服務供應商和託管服務會按照各自的政策處理資料。

移除已儲存的資料

刪除牌組會從此 App 中移除該牌組儲存的文字、本機照片或 PDF 副本、產生的學習資料和進度。使用相同資料的其他牌組會保留各自的副本。「移除連線」會刪除已儲存的個人金鑰。此 App 以外的檔案、備份和服務供應商端的資料須另行管理。

服務紀錄與供應商保留

使用 Pro 雲端服務時： Pro 透過 Vercel 將已確認的資料傳送給 OpenAI。我們不在伺服器上建立學習檔案庫，也不刻意將學習內容寫入日誌。這不等於零保留：供應商與基礎設施的政策仍適用。OpenAI 請求使用 store:false；預設濫用監控內容可能保留最多 30 天，另有法律與安全例外。訂閱存取、安全與額度管理使用簽署的 Apple 交易、穩定的訂閱及請求雜湊識別碼，以及 UTC 計數器。這些識別碼並非匿名。每日計數器在最後更新後 3 天到期，每月計數器在 35 天後到期；用於偵測重複請求的摘要不會自動到期。刪除本機卡組不會刪除這些紀錄、供應商紀錄、作業系統備份或支援往來郵件。如需申請處理服務資料，請聯絡我們；切勿傳送秘密金鑰或密碼。
