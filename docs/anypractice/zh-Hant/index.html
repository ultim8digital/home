隱私權政策 ↗

AI 供應商

沒有有效的 Pro 訂閱時，產生內容需要使用自己的 API 金鑰。除非你明確選擇其他供應商，否則 Pro 預設使用我們的服務。只有在裝置以及來源和問題的兩種語言均受支援時，Pro 使用者才能選擇 Apple Intelligence 產生以來源為基礎的記憶卡草稿。產生課程、摘要和測驗需要雲端連線。Pro 到期會阻止透過 Pro 產生；Apple 無法使用時會阻止所選的 Apple 路徑。App 不會自動切換供應商。 使用個人 API 金鑰連接 OpenAI、Anthropic、Gemini 或相容供應商。API 使用費由供應商另外收取。

AnyPractice Pro — 推薦

使用最好的模型建立課程、講解、摘要和練習。

使用 Pro 雲端服務時： Pro 每個 UTC 日曆月包含最多 60 次已開始的產生請求，每個 UTC 日最多 5 次。服務整體的使用量與預算限制可能在你的個人配額用完前暫停產生內容。請求一旦開始，即使失敗或中斷也會計入。已儲存的資料仍可離線使用。

美國價格：每月 6.99 美元或每年 49.99 美元，自動續訂。當地價格、可用情況與最終條款以 App Store 顯示為準。在 Apple 帳號中管理或取消訂閱，在應用程式中回復購買項目。
