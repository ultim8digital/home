ଆପଣଙ୍କ ସାମଗ୍ରୀ। ଆପଣଙ୍କ ପସନ୍ଦ।

ପାଠ୍ୟ ଚିହ୍ନଟ ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ଚାଲେ। ଆମଦାନି ହୋଇଥିବା ଫଟୋ ଓ PDF ମଧ୍ୟ ଆପଣଙ୍କ ସାମଗ୍ରୀ ସହ ସ୍ଥାନୀୟ ଭାବେ ସଂରକ୍ଷିତ ହୁଏ। Pro ପାଠ ପାଇଁ, ସମୀକ୍ଷା କରି ନିଶ୍ଚିତ କରିବା ପରେ ଆପଣ ଫଟୋ କିମ୍ବା ବଛାଯାଇଥିବା ସମ୍ପୂର୍ଣ୍ଣ PDF ପୃଷ୍ଠା OpenAIକୁ ପଠାଇପାରିବେ। କେବଳ ପାଠ୍ୟ ମୋଡ୍‌ଗୁଡ଼ିକ ସମୀକ୍ଷା ହୋଇଥିବା ପାଠ୍ୟ ହିଁ ପଠାଏ।

AI ପ୍ରଦାନକାରୀ

ସକ୍ରିୟ Pro ବିନା ସୃଷ୍ଟି ପାଇଁ ନିଜର API କୀ ଦରକାର। ଆପଣ ସ୍ପଷ୍ଟ ଭାବେ ଅନ୍ୟ ପ୍ରଦାନକାରୀ ବାଛି ନଥିଲେ Pro ଡିଫଲ୍ଟ ଭାବେ ଆମ ସେବା ବ୍ୟବହାର କରେ। ଉପକରଣ ଏବଂ ଉତ୍ସ ଓ ପ୍ରଶ୍ନର ଉଭୟ ଭାଷା ସମର୍ଥିତ ଥିଲେ ଉତ୍ସଭିତ୍ତିକ ଫ୍ଲାଶ୍‌କାର୍ଡ ଖସଡ଼ା ପାଇଁ Apple Intelligence କେବଳ Pro ରେ ଉପଲବ୍ଧ। ପାଠ, ସାରାଂଶ ଓ କୁଇଜ୍ ସୃଷ୍ଟି ପାଇଁ କ୍ଲାଉଡ୍ ସଂଯୋଗ ଦରକାର। Pro ସମୟସୀମା ସରିଲେ Pro ସୃଷ୍ଟି ବନ୍ଦ ହୁଏ; Apple ଅନୁପଲବ୍ଧ ଥିଲେ ବାଛିଥିବା Apple ପଥ ବନ୍ଦ ହୁଏ। ଆପ୍ ପ୍ରଦାନକାରୀକୁ ଆପେଆପେ ବଦଳାଏ ନାହିଁ। OpenAI, Anthropic, Gemini କିମ୍ବା ସୁସଙ୍ଗତ ପ୍ରଦାନକାରୀ ସହ ବ୍ୟକ୍ତିଗତ API କୀ ବ୍ୟବହାର କରନ୍ତୁ। ପ୍ରଦାନକାରୀ API ବ୍ୟବହାର ପାଇଁ ଅଲଗା ଶୁଳ୍କ ନିଏ।

Pro କ୍ଲାଉଡ୍ ସେବା ବ୍ୟବହାର କରିବା ସମୟରେ: Proରେ ପ୍ରତି UTC କ୍ୟାଲେଣ୍ଡର ମାସରେ ସର୍ବାଧିକ 60ଟି ଆରମ୍ଭ ହୋଇଥିବା ସୃଷ୍ଟି ଅନୁରୋଧ ଓ ପ୍ରତି UTC ଦିନରେ ସର୍ବାଧିକ 5ଟି ରହିଛି। ସେବାର ସାମଗ୍ରିକ ବ୍ୟବହାର ଓ ବଜେଟ୍ ସୀମା ଯୋଗୁଁ ଆପଣଙ୍କ ବ୍ୟକ୍ତିଗତ କୋଟା ସରିବା ପୂର୍ବରୁ ସୃଷ୍ଟି ପ୍ରକ୍ରିୟା ସାମୟିକ ଭାବେ ବନ୍ଦ ହୋଇପାରେ। ଆରମ୍ଭ ହୋଇଥିବା ଅନୁରୋଧ ବିଫଳ ବା ବାଧାପ୍ରାପ୍ତ ହେଲେ ମଧ୍ୟ ଗଣାଯାଏ। ସଞ୍ଚିତ ସାମଗ୍ରୀ ଅଫଲାଇନ୍‌ରେ ଉପଲବ୍ଧ ରହେ।
