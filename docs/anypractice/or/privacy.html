ଗୋପନୀୟତା ନୀତି

ଆପଣଙ୍କ ସାମଗ୍ରୀ। ଆପଣଙ୍କ ପସନ୍ଦ।

AnyPractice · Oleg Korunov / ULTIMATE DIGITAL · ultim8digital@gmail.com

ଏହି ପୃଷ୍ଠାରେ
ସ୍ଥାନୀୟ ଲାଇବ୍ରେରିଫଟୋ ଏବଂ PDFAI ପ୍ରଦାନକାରୀApple IntelligenceAnyPractice Proସଞ୍ଚିତ ତଥ୍ୟ ହଟାନ୍ତୁସେବା ରେକର୍ଡ ଓ ପ୍ରଦାନକାରୀଙ୍କ ସଂରକ୍ଷଣସହାୟତା

ସ୍ଥାନୀୟ ଲାଇବ୍ରେରି

ବାହାର କରାଯାଇଥିବା ଅଧ୍ୟୟନ ଲେଖା, ପାଠ, କାର୍ଡ ଏବଂ ପ୍ରଗତି ଆପଣଙ୍କ ଡିଭାଇସ୍‌ର ଏହି ଆପ୍‌ରେ ସଞ୍ଚିତ ହୁଏ। ଆପ୍ AnyPractice ଆକାଉଣ୍ଟ ତିଆରି କରେ ନାହିଁ କିମ୍ବା ନିଜସ୍ୱ କ୍ଲାଉଡ୍ ସିଙ୍କ ଦିଏ ନାହିଁ। ଡିଭାଇସ୍ ବ୍ୟାକଅପ୍‌ରେ ଆପ୍‌ର ସ୍ଥାନୀୟ ତଥ୍ୟ ରହିପାରେ।

ଫଟୋ ଏବଂ PDF

ପାଠ୍ୟ ଚିହ୍ନଟ ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ଚାଲେ। ଆମଦାନି ହୋଇଥିବା ଫଟୋ ଓ PDF ମଧ୍ୟ ଆପଣଙ୍କ ସାମଗ୍ରୀ ସହ ସ୍ଥାନୀୟ ଭାବେ ସଂରକ୍ଷିତ ହୁଏ। Pro ପାଠ ପାଇଁ, ସମୀକ୍ଷା କରି ନିଶ୍ଚିତ କରିବା ପରେ ଆପଣ ଫଟୋ କିମ୍ବା ବଛାଯାଇଥିବା ସମ୍ପୂର୍ଣ୍ଣ PDF ପୃଷ୍ଠା OpenAIକୁ ପଠାଇପାରିବେ। କେବଳ ପାଠ୍ୟ ମୋଡ୍‌ଗୁଡ଼ିକ ସମୀକ୍ଷା ହୋଇଥିବା ପାଠ୍ୟ ହିଁ ପଠାଏ।

AI ପ୍ରଦାନକାରୀ

ସକ୍ରିୟ Pro ବିନା ସୃଷ୍ଟି ପାଇଁ ନିଜର API କୀ ଦରକାର। ଆପଣ ସ୍ପଷ୍ଟ ଭାବେ ଅନ୍ୟ ପ୍ରଦାନକାରୀ ବାଛି ନଥିଲେ Pro ଡିଫଲ୍ଟ ଭାବେ ଆମ ସେବା ବ୍ୟବହାର କରେ। ଉପକରଣ ଏବଂ ଉତ୍ସ ଓ ପ୍ରଶ୍ନର ଉଭୟ ଭାଷା ସମର୍ଥିତ ଥିଲେ ଉତ୍ସଭିତ୍ତିକ ଫ୍ଲାଶ୍‌କାର୍ଡ ଖସଡ଼ା ପାଇଁ Apple Intelligence କେବଳ Pro ରେ ଉପଲବ୍ଧ। ପାଠ, ସାରାଂଶ ଓ କୁଇଜ୍ ସୃଷ୍ଟି ପାଇଁ କ୍ଲାଉଡ୍ ସଂଯୋଗ ଦରକାର। Pro ସମୟସୀମା ସରିଲେ Pro ସୃଷ୍ଟି ବନ୍ଦ ହୁଏ; Apple ଅନୁପଲବ୍ଧ ଥିଲେ ବାଛିଥିବା Apple ପଥ ବନ୍ଦ ହୁଏ। ଆପ୍ ପ୍ରଦାନକାରୀକୁ ଆପେଆପେ ବଦଳାଏ ନାହିଁ। OpenAI, Anthropic, Gemini କିମ୍ବା ସୁସଙ୍ଗତ ପ୍ରଦାନକାରୀ ସହ ବ୍ୟକ୍ତିଗତ API କୀ ବ୍ୟବହାର କରନ୍ତୁ। ପ୍ରଦାନକାରୀ API ବ୍ୟବହାର ପାଇଁ ଅଲଗା ଶୁଳ୍କ ନିଏ। ଆପଣଙ୍କ API କୀ ସହିତ କେବଳ ଚୟନିତ ଅଂଶ ଏବଂ ସୃଷ୍ଟି ନିର୍ଦ୍ଦେଶ ଆପଣ ନିଶ୍ଚିତ କରିଥିବା ପ୍ରଦାନକାରୀ ଓ ମଡେଲ୍‌କୁ ସିଧା ପଠାଯାଏ। ଆପଣଙ୍କ କୀ ଏହି ଡିଭାଇସ୍‌ର Keychainରେ ସଞ୍ଚିତ ରହେ। ପ୍ରଦାନକାରୀ ନିଜ ସର୍ତ୍ତ ଅନୁସାରେ ଅନୁରୋଧ ରଖିପାରନ୍ତି। ସେହି ପ୍ରଦାନକାରୀଙ୍କ ପାଖରେ ପୂର୍ବରୁ ଥିବା କପି AnyPractice ବିଲୋପ କରିପାରେ ନାହିଁ।

Apple Intelligence

ଏହି ବିକଳ୍ପ ପାଇଁ ସକ୍ରିୟ Pro ସଦସ୍ୟତା ଦରକାର। Apple Intelligence ସମର୍ଥିତ ଡିଭାଇସ୍‌ରେ ଉତ୍ସ-ଆଧାରିତ ଫ୍ଲାଶକାର୍ଡ ତିଆରି କରେ। ସୃଷ୍ଟି ଏବଂ ସମର୍ଥିତ ଅନୁବାଦ ସ୍ଥାନୀୟ ଭାବେ ହୁଏ; ଭାଷା ସମ୍ପଦ ଡାଉନଲୋଡ୍ କରିବାକୁ ପଡ଼ିପାରେ।

AnyPractice Pro

Pro କ୍ଲାଉଡ୍ ସେବା ବ୍ୟବହାର କରିବା ସମୟରେ: Proରେ ବଛାଯାଇଥିବା ପାଠ୍ୟ ଓ ନିଶ୍ଚିତ ହୋଇଥିବା ମୂଳ ପୃଷ୍ଠାଗୁଡ଼ିକ Vercelରେ ଥିବା AnyPractice ମାଧ୍ୟମରେ OpenAIକୁ ଯାଏ। ସର୍ଭରରେ ଫାଇଲ ଲାଇବ୍ରେରୀ ତିଆରି ନକରି, ସେହି ଅନୁରୋଧ ପାଇଁ ମୂଳ ଫାଇଲଗୁଡ଼ିକ ପ୍ରକ୍ରିୟାକରଣ କରାଯାଏ। Apple ଦେୟ ପ୍ରକ୍ରିୟାକରଣ କରେ; ସର୍ଭର ଆପଣଙ୍କ ସଦସ୍ୟତା ଯାଞ୍ଚ କରେ ଏବଂ ପରିଚୟସୂଚକ ଓ ବ୍ୟବହାର ଗଣନା ସଂରକ୍ଷଣ କରେ। ପ୍ରଦାନକାରୀ ଓ ହୋଷ୍ଟିଂ ସେବାଗୁଡ଼ିକ ନିଜ ନୀତି ଅନୁଯାୟୀ ତଥ୍ୟ ପରିଚାଳନା କରନ୍ତି।

ସଞ୍ଚିତ ତଥ୍ୟ ହଟାନ୍ତୁ

ଡେକ୍ ଡିଲିଟ୍ କଲେ ଏହି ଆପ୍‌ରୁ ଏହାର ସଂରକ୍ଷିତ ପାଠ୍ୟ, ଫଟୋ କିମ୍ବା PDFର ସ୍ଥାନୀୟ ନକଲ, ତିଆରି ହୋଇଥିବା ସାମଗ୍ରୀ ଓ ଅଗ୍ରଗତି ହଟିଯିବ। ସେହି ସାମଗ୍ରୀ ବ୍ୟବହାର କରୁଥିବା ଅନ୍ୟ ଡେକ୍‌ଗୁଡ଼ିକ ସେମାନଙ୍କର ନକଲ ରଖିବେ। «ସଂଯୋଗ ହଟାନ୍ତୁ» ସଂରକ୍ଷିତ ବ୍ୟକ୍ତିଗତ କୀ ଡିଲିଟ୍ କରେ। ଏହି ଆପ୍ ବାହାରର ଫାଇଲ, ବ୍ୟାକଅପ୍ ଓ ପ୍ରଦାନକାରୀଙ୍କ ପାଖରେ ଥିବା ତଥ୍ୟ ଅଲଗା।

ସେବା ରେକର୍ଡ ଓ ପ୍ରଦାନକାରୀଙ୍କ ସଂରକ୍ଷଣ

Pro କ୍ଲାଉଡ୍ ସେବା ବ୍ୟବହାର କରିବା ସମୟରେ: Pro ଅନୁମୋଦିତ ସାମଗ୍ରୀ Vercel ମାଧ୍ୟମରେ OpenAIକୁ ପଠାଏ। ଆମେ ସର୍ଭରରେ ପାଠ୍ୟ ଫାଇଲ୍‌ର ଲାଇବ୍ରେରି ରଖୁନାହୁଁ କିମ୍ବା ଜାଣିଶୁଣି ପାଠ୍ୟ ବିଷୟବସ୍ତୁ ଲଗ୍ କରୁନାହୁଁ। ଏହା ଶୂନ୍ୟ ସଂରକ୍ଷଣ ନୁହେଁ: ପ୍ରଦାନକାରୀ ଓ ଭିତ୍ତିଭୂମି ନୀତି ଲାଗୁ ରହେ। OpenAI ଅନୁରୋଧ store:false ବ୍ୟବହାର କରେ; ସାଧାରଣ ଅପବ୍ୟବହାର ନିରୀକ୍ଷଣ ବିଷୟବସ୍ତୁ ଆଇନଗତ/ସୁରକ୍ଷା ବ୍ୟତିକ୍ରମ ସହ 30 ଦିନ ପର୍ଯ୍ୟନ୍ତ ରହିପାରେ। ସଦସ୍ୟତା ପ୍ରବେଶ, ସୁରକ୍ଷା ଓ ସୀମା ପାଇଁ ସ୍ୱାକ୍ଷରିତ Apple କାରବାର, ସ୍ଥିର ହ୍ୟାଶ୍ କରା ସଦସ୍ୟତା/ଅନୁରୋଧ ପରିଚୟ ଓ UTC କାଉଣ୍ଟର ବ୍ୟବହୃତ ହୁଏ। ଏହି ପରିଚୟଗୁଡ଼ିକ ଅନାମ ନୁହେଁ। ଦୈନିକ କାଉଣ୍ଟର ଶେଷ ଅଦ୍ୟତନର 3 ଦିନ ପରେ, ମାସିକ କାଉଣ୍ଟର 35 ଦିନ ପରେ ସମାପ୍ତ ହୁଏ; ନକଲ ଅନୁରୋଧ ଚିହ୍ନଟ ହ୍ୟାଶ୍ ସ୍ୱୟଂଚାଳିତ ସମାପ୍ତ ହୁଏନାହିଁ। ସ୍ଥାନୀୟ ଡେକ୍ ହଟାଇଲେ ଏହି ରେକର୍ଡ, ପ୍ରଦାନକାରୀ ରେକର୍ଡ, ଅପରେଟିଂ ସିଷ୍ଟମ୍ ବ୍ୟାକଅପ୍ ବା ସହାୟତା ଚିଠିପତ୍ର ହଟେନାହିଁ। ସେବା ତଥ୍ୟ ଅନୁରୋଧ ପାଇଁ ଯୋଗାଯୋଗ କରନ୍ତୁ; ଗୁପ୍ତ କୀ ବା ପାସୱାର୍ଡ କେବେ ପଠାନ୍ତୁ ନାହିଁ।

ସହାୟତା

ଶିକ୍ଷାର୍ଥୀ ଖାତା, ବିଜ୍ଞାପନ SDK ବା ଆପ୍‌ମଧ୍ୟରେ ଟ୍ରାକିଂ ନାହିଁ। ସାଇଟ୍ ବିଶ୍ଳେଷଣ କୁକି ବା ବିଜ୍ଞାପନ ସ୍କ୍ରିପ୍ଟ ବ୍ୟବହାର କରେନାହିଁ। GitHub Pages ତଥାପି ସାଧାରଣ ହୋଷ୍ଟିଂ/ନେଟୱର୍କ ଅନୁରୋଧ ପ୍ରକ୍ରିୟା କରେ। ସହାୟତା ଇମେଲ୍ ଓ ଇଚ୍ଛାରେ ପଠାଇଥିବା ତଥ୍ୟ ଉତ୍ତର ଦେବା ଓ ସମସ୍ୟା ତଦନ୍ତରେ ବ୍ୟବହୃତ ହୁଏ। ଦେୟ Apple ପରିଚାଳନା କରେ; ଆମେ କାର୍ଡ ତଥ୍ୟ ବା Apple ପାସୱାର୍ଡ ପାଉନାହୁଁ। AnyPractice ପ୍ରାପ୍ତବୟସ୍କ, ଅଭିଭାବକ ଓ ଶିକ୍ଷକଙ୍କ ପାଇଁ।
