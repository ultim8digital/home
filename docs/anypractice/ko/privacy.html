로컬 라이브러리

추출된 학습 텍스트, 수업, 카드와 학습 진도는 기기에 있는 이 앱에 저장됩니다. 앱은 AnyPractice 계정을 만들지 않으며 자체 클라우드 동기화를 제공하지 않습니다. 기기 백업에 앱의 로컬 데이터가 포함될 수 있습니다.

사진 및 PDF

텍스트 인식은 기기에서 실행됩니다. 가져온 사진과 PDF도 자료와 함께 기기에 저장됩니다. Pro 수업에서는 검토하고 확인한 후 사진이나 선택한 PDF 전체 페이지를 OpenAI로 보낼 수 있습니다. 텍스트 전용 모드에서는 검토한 텍스트만 보냅니다.

AI 제공업체

활성 Pro 구독이 없으면 생성에 개인 API 키가 필요합니다. 다른 제공업체를 명시적으로 선택하지 않는 한 Pro는 당사의 서비스를 기본으로 사용합니다. Apple Intelligence는 기기와 출처 및 질문 언어가 모두 지원되는 경우 출처 기반 암기 카드 초안을 만드는 Pro 전용 옵션입니다. 수업, 요약, 퀴즈 생성에는 클라우드 연결이 필요합니다. Pro가 만료되면 Pro 생성이 차단되며, Apple을 사용할 수 없으면 선택한 Apple 경로가 차단됩니다. 앱은 제공업체를 자동으로 전환하지 않습니다. 개인 API 키로 OpenAI, Anthropic, Gemini 또는 호환 제공업체를 이용하세요. API 사용료는 제공업체에서 별도로 청구합니다. 본인의 API 키를 사용하면 선택한 발췌문과 생성 지침만 확인한 제공업체 및 모델로 직접 전송됩니다. 키는 이 기기의 Keychain에 저장됩니다. 제공업체는 자체 약관에 따라 요청을 보관할 수 있습니다. AnyPractice는 해당 제공업체가 이미 보유한 사본을 삭제할 수 없습니다.

Apple Intelligence

이 옵션에는 활성 Pro 구독이 필요합니다. Apple Intelligence는 지원되는 기기에서 원본 자료를 바탕으로 학습 카드를 만듭니다. 생성과 지원되는 번역은 기기에서 실행되며, 언어 리소스를 다운로드해야 할 수 있습니다.

AnyPractice Pro

Pro 클라우드 서비스를 사용할 때: Pro를 사용하면 선택한 텍스트와 전송을 확인한 원본 페이지가 Vercel의 AnyPractice를 거쳐 OpenAI로 전송됩니다. 원본 파일은 해당 요청을 위해 처리되며, 서버에 파일 라이브러리를 만들지 않습니다. Apple이 결제를 처리하고 서버는 구독을 확인하며 식별자와 사용량 카운터를 저장합니다. 제공업체와 호스팅 서비스는 각자의 정책에 따라 데이터를 처리합니다.

저장된 데이터 삭제

덱을 삭제하면 저장된 텍스트, 기기에 저장된 사진 또는 PDF 사본, 생성된 자료와 학습 진행 상황이 이 앱에서 삭제됩니다. 같은 자료를 사용하는 다른 덱의 사본은 유지됩니다. «연결 삭제»를 선택하면 저장된 개인 키가 삭제됩니다. 이 앱 외부의 파일, 백업, 제공업체 측 데이터는 별개입니다.

서비스 기록 및 제공업체 보관

Pro 클라우드 서비스를 사용할 때: Pro는 확인된 자료를 Vercel을 통해 OpenAI로 전달합니다. 서버에 학습 파일 라이브러리를 유지하거나 학습 내용을 의도적으로 로그에 기록하지 않습니다. 이는 보관이 전혀 없다는 뜻이 아니며 제공업체와 인프라 정책은 계속 적용됩니다. OpenAI 요청은 store:false를 사용하지만 기본 오용 모니터링 내용은 법적·안전상 예외와 함께 최대 30일 보관될 수 있습니다. 구독 접근, 보안, 한도 관리에는 서명된 Apple 거래, 고정된 해시 구독·요청 식별자와 UTC 카운터를 사용합니다. 이 식별자는 익명이 아닙니다. 일별 카운터는 마지막 갱신 후 3일, 월별 카운터는 35일 후 만료되며 중복 요청 감지용 다이제스트는 자동 만료되지 않습니다. 로컬 덱을 삭제해도 이러한 기록, 제공업체 기록, 운영체제 백업 또는 지원 서신은 삭제되지 않습니다. 서비스 데이터 요청은 문의해 주세요. 비밀 키나 암호는 절대 보내지 마세요.
