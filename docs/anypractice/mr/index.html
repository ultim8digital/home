AI प्रदाते

सक्रिय Pro शिवाय निर्मितीसाठी स्वतःची API की आवश्यक आहे. तुम्ही स्पष्टपणे दुसरा प्रदाता निवडत नाही तोपर्यंत Pro डीफॉल्टने आमची सेवा वापरते. उपकरण आणि स्रोत व प्रश्नांच्या दोन्ही भाषा समर्थित असल्यास स्रोताधारित फ्लॅशकार्डच्या मसुद्यांसाठी Apple Intelligence केवळ Pro मध्ये उपलब्ध असते. धडे, सारांश आणि प्रश्नमंजुषा तयार करण्यासाठी क्लाउड कनेक्शन आवश्यक आहे. Pro ची मुदत संपल्यास Pro निर्मिती थांबते; Apple अनुपलब्ध असल्यास निवडलेला Apple मार्ग थांबतो. ॲप प्रदाता आपोआप बदलत नाही. OpenAI, Anthropic, Gemini किंवा सुसंगत प्रदात्यासोबत वैयक्तिक API की वापरा. API वापराचे शुल्क प्रदाता स्वतंत्रपणे आकारतो.
