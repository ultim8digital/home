你的材料

导入或粘贴资料，选择学习模式并检查所选 AI 连接。 没有有效的 Pro 订阅时，生成内容需要使用自己的 API 密钥。除非你明确选择其他服务商，否则 Pro 默认使用我们的服务。只有在设备以及来源和问题的两种语言均受支持时，Pro 用户才能选择 Apple Intelligence 生成基于来源的记忆卡草稿。生成课程、摘要和测验需要云端连接。Pro 到期会阻止通过 Pro 生成；Apple 不可用时会阻止所选的 Apple 路径。应用不会自动切换服务商。 已保存的课程和练习可离线使用。

照片和 PDF

使用清晰、光线充足的照片，并检查识别出的文字。Pro 课程允许你明确确认发送原始照片或所选 PDF 整页；整页可能包含未选中的文字。个人服务商和来源卡片生成仅使用文本。

AnyPractice Pro — 推荐

使用最好的模型创建课程、讲解、摘要和练习。

使用 Pro 云端服务时： Pro 每个 UTC 日历月包含最多 60 次已开始的生成请求，每个 UTC 日最多 5 次。服务整体的使用量和预算限制可能在你的个人配额用完前暂停生成。请求一旦开始，即使失败或中断也会计入。已保存的资料仍可离线使用。

美国定价：每月 6.99 美元或每年 49.99 美元，自动续订。当地价格、可用情况和最终条款以 App Store 显示为准。在 Apple 账户中管理或取消订阅，在应用中恢复购买。

没有有效的 Pro 订阅时，生成内容需要使用自己的 API 密钥。除非你明确选择其他服务商，否则 Pro 默认使用我们的服务。只有在设备以及来源和问题的两种语言均受支持时，Pro 用户才能选择 Apple Intelligence 生成基于来源的记忆卡草稿。生成课程、摘要和测验需要云端连接。Pro 到期会阻止通过 Pro 生成；Apple 不可用时会阻止所选的 Apple 路径。应用不会自动切换服务商。 使用个人 API 密钥连接 OpenAI、Anthropic、Gemini 或兼容服务商。API 使用费由服务商单独收取。

举报生成的内容

AI 可能会出错。你可以在应用内编辑或删除生成的资料。如需举报有害内容，请描述问题，不要包含私人信息。

移除已保存的数据

删除牌组会从此 App 中移除该牌组保存的文本、本地照片或 PDF 副本、生成的学习资料和进度。使用同一资料的其他牌组会保留各自的副本。“移除连接”会删除已保存的个人密钥。此 App 之外的文件、备份和服务商端的数据需另行管理。
