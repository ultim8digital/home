隐私政策

本地资料库

提取的学习文本、课程、卡片和进度会保存在你设备上的本应用中。应用不会创建 AnyPractice 账户，也不提供自有云同步服务。设备备份可能包含应用的本地数据。

照片和 PDF

文本识别在你的设备上运行。导入的照片和 PDF 也会随学习资料一起保存在本地。使用 Pro 课程时，你可以在审阅并确认后，将照片或所选的完整 PDF 页面发送给 OpenAI。纯文本模式仅发送经过审阅的文本。

AI 提供商

没有有效的 Pro 订阅时，生成内容需要使用自己的 API 密钥。除非你明确选择其他服务商，否则 Pro 默认使用我们的服务。只有在设备以及来源和问题的两种语言均受支持时，Pro 用户才能选择 Apple Intelligence 生成基于来源的记忆卡草稿。生成课程、摘要和测验需要云端连接。Pro 到期会阻止通过 Pro 生成；Apple 不可用时会阻止所选的 Apple 路径。应用不会自动切换服务商。 使用个人 API 密钥连接 OpenAI、Anthropic、Gemini 或兼容服务商。API 使用费由服务商单独收取。 使用你自己的 API 密钥时，只有选定的段落和生成指令会直接发送至你确认的提供商和模型。密钥保存在此设备的 Keychain 中。提供商可能会根据自身条款保留请求。AnyPractice 无法删除该提供商已持有的副本。

Apple 智能

此选项需要有效的 Pro 订阅。 Apple Intelligence 可在支持的设备上根据原始资料创建学习卡片。生成和受支持的翻译均在设备本地进行；可能需要下载语言资源。

AnyPractice Pro

使用 Pro 云端服务时： 使用 Pro 时，所选文本和你确认发送的原始页面会通过 Vercel 上的 AnyPractice 传送给 OpenAI。原始文件仅为该请求进行处理，服务器不设文件库。Apple 负责处理付款；服务器验证你的订阅，并保存标识符和用量计数。服务商和托管服务会按照各自的政策处理数据。

移除已保存的数据

删除牌组会从此 App 中移除该牌组保存的文本、本地照片或 PDF 副本、生成的学习资料和进度。使用同一资料的其他牌组会保留各自的副本。“移除连接”会删除已保存的个人密钥。此 App 之外的文件、备份和服务商端的数据需另行管理。

服务记录与服务商留存

使用 Pro 云端服务时： Pro 通过 Vercel 将已确认的资料发送给 OpenAI。我们不在服务器上建立学习文件库，也不有意将学习内容写入日志。这不等于零留存：服务商和基础设施的政策仍然适用。OpenAI 请求使用 store:false；默认滥用监控内容可能保留最多 30 天，另有法律和安全例外。订阅访问、安全和额度管理使用签名的 Apple 交易、稳定的订阅及请求哈希标识符和 UTC 计数器。这些标识符并非匿名。日计数器在最后更新后 3 天到期，月计数器在 35 天后到期；用于检测重复请求的摘要不会自动到期。删除本地卡组不会删除这些记录、服务商记录、操作系统备份或支持邮件往来。如需申请处理服务数据，请联系我们；切勿发送秘密密钥或密码。

支持

无需学习者账户，没有广告 SDK 或跨应用追踪。网站不使用分析 Cookie 或广告脚本。GitHub Pages 仍会处理常规托管和网络请求。支持邮箱和你自愿发送的信息用于回复和调查问题。付款由 Apple 处理，我们不会收到银行卡信息或 Apple 密码。AnyPractice 面向成年人、家长和教师。
