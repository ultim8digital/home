المكتبة المحلية

يُحفظ نص الدراسة المستخرج والدروس والبطاقات والتقدّم في هذا التطبيق على جهازك. لا ينشئ التطبيق حساب AnyPractice ولا يوفّر مزامنة سحابية خاصة به. قد تتضمن النسخ الاحتياطية للجهاز بيانات التطبيق المحلية.

الصور وملفات PDF

يعمل التعرّف على النصوص على جهازك. تُحفظ الصور وملفات PDF المستوردة محليًا أيضًا مع مادتك. لدروس Pro، يمكنك إرسال الصورة أو صفحات PDF المحددة كاملةً إلى OpenAI بعد مراجعتها وتأكيد الإرسال. ترسل الأوضاع النصية النص الذي راجعته فقط.

مزوّدو الذكاء الاصطناعي

من دون اشتراك Pro نشط، يتطلب التوليد مفتاح API خاصًا بك. يستخدم Pro خدمتنا افتراضيًا ما لم تختر مزوّدًا آخر صراحةً. يتوفر Apple Intelligence مع Pro فقط لمسودات البطاقات المستندة إلى المصادر، إذا كان الجهاز ولغتا المصدر والأسئلة مدعومة. يتطلب توليد الدروس والملخصات والاختبارات اتصالًا سحابيًا. يمنع انتهاء Pro التوليد عبر Pro؛ ويُحظر مسار Apple المحدد إذا لم يكن متاحًا. لا يغير التطبيق المزوّد تلقائيًا. استخدم مفتاح API شخصيًا مع OpenAI أو Anthropic أو Gemini أو مزوّد متوافق. يفرض المزوّد رسوم استخدام API بشكل منفصل. عند استخدام مفتاح API الخاص بك، تُرسل المقاطع المحددة وتعليمات إنشاء المحتوى فقط مباشرةً إلى المزوّد والنموذج اللذين تؤكدهما. يُحفظ مفتاحك في Keychain على هذا الجهاز. قد يحتفظ المزوّد بالطلبات وفق شروطه الخاصة. لا يستطيع AnyPractice حذف النسخ التي يحتفظ بها ذلك المزوّد بالفعل.

Apple Intelligence

يتطلب هذا الخيار اشتراك Pro نشطًا. ينشئ Apple Intelligence بطاقات تعليمية تستند إلى المادة الأصلية على الأجهزة المدعومة. يجري إنشاء المحتوى والترجمة المدعومة محليًا؛ وقد يلزم تنزيل موارد اللغات.

AnyPractice Pro

عند استخدام خدمة Pro السحابية: مع Pro، يمر النص المحدد وأي صفحات أصلية أكدت إرسالها عبر AnyPractice على Vercel إلى OpenAI. تُعالج الملفات الأصلية لذلك الطلب من دون إنشاء مكتبة ملفات على الخادم. تعالج Apple المدفوعات؛ ويتحقق الخادم من اشتراكك ويحفظ المعرّفات وعدّادات الاستخدام. تتعامل خدمات المزوّد والاستضافة مع البيانات وفق سياساتها الخاصة.

إزالة البيانات المحفوظة

احذف المجموعة لإزالة نصها المحفوظ ونسخة الصورة أو ملف PDF المحلية والمواد التي أُنشئت وتقدّمك من هذا التطبيق. تحتفظ المجموعات الأخرى التي تستخدم المادة نفسها بنسخها. يؤدي «إزالة الاتصال» إلى حذف مفتاحك الشخصي المحفوظ. الملفات خارج هذا التطبيق والنسخ الاحتياطية والبيانات لدى مزوّد الخدمة منفصلة عن ذلك.

سجلات الخدمة واحتفاظ المزوّدين

عند استخدام خدمة Pro السحابية: يمرر Pro المادة المؤكدة عبر Vercel إلى OpenAI. لا نحتفظ بمكتبة ملفات دراسية على الخادم ولا نسجّل محتوى الدراسة عمدًا في السجلات. هذا لا يعني انعدام الاحتفاظ: تظل سياسات المزوّدين والبنية التحتية سارية. تستخدم طلبات OpenAI القيمة store:false؛ وقد يبقى محتوى مراقبة إساءة الاستخدام الافتراضية حتى 30 يومًا، مع استثناءات قانونية وأمنية. يستخدم الوصول للاشتراك والأمان والحدود معاملات Apple الموقّعة ومعرّفات ثابتة مجزّأة للاشتراكات والطلبات وعدادات UTC. هذه المعرّفات ليست مجهولة الهوية. تنتهي العدادات اليومية بعد 3 أيام من آخر تحديث، والشهرية بعد 35 يومًا؛ ولا تنتهي بصمات كشف الطلبات المكررة تلقائيًا. حذف مجموعة بطاقات محلية لا يحذف هذه السجلات أو سجلات المزوّدين أو نسخ نظام التشغيل الاحتياطية أو مراسلات الدعم. تواصل معنا لطلبات بيانات الخدمة؛ ولا ترسل أبدًا مفتاحًا سريًا أو كلمة مرور.

الدعم

لا حساب متعلّم ولا حزم SDK إعلانية ولا تتبّع عبر التطبيقات. لا يستخدم هذا الموقع ملفات تعريف ارتباط تحليلية أو نصوصًا إعلانية. يظل GitHub Pages يعالج طلبات الاستضافة والشبكة المعتادة. يُستخدم بريد الدعم والمعلومات التي تختار إرسالها للرد والتحقيق في المشكلات. تتولى Apple المدفوعات؛ ولا نتلقى بيانات البطاقات أو كلمات مرور Apple.
