தனியுரிமைக் கொள்கை

உங்கள் பாடப்பொருள். உங்கள் தேர்வு.

இந்தப் பக்கத்தில்
சாதன நூலகம்படங்களும் PDFகளும்AI வழங்குநர்கள்Apple IntelligenceAnyPractice Proசேமித்த தரவை அகற்றுசேவைப் பதிவுகளும் வழங்குநரின் தரவுத் தக்கவைப்பும்ஆதரவு

சாதன நூலகம்

பிரித்தெடுத்த படிப்பு உரை, பாடங்கள், அட்டைகள் மற்றும் முன்னேற்றம் உங்கள் சாதனத்தில் இந்த ஆப்பில் சேமிக்கப்படும். ஆப் AnyPractice கணக்கை உருவாக்கவோ தனது சொந்த கிளவுட் ஒத்திசைவை வழங்கவோ செய்யாது. சாதனக் காப்புப்பிரதிகளில் ஆப்பின் உள்ளூர் தரவு இருக்கலாம்.

படங்களும் PDFகளும்

உரை கண்டறிதல் உங்கள் சாதனத்தில் இயங்குகிறது. இறக்குமதி செய்த புகைப்படங்களும் PDF-களும் உங்கள் பாடப்பொருளுடன் சாதனத்திலேயே சேமிக்கப்படுகின்றன. Pro பாடங்களுக்கு, மதிப்பாய்வு செய்து உறுதிசெய்த பிறகு புகைப்படத்தையோ தேர்ந்தெடுத்த முழு PDF பக்கங்களையோ OpenAI-க்கு அனுப்பலாம். உரை மட்டும் பயன்படுத்தும் முறைகள் மதிப்பாய்வு செய்த உரையை மட்டுமே அனுப்பும்.

AI வழங்குநர்கள்

செயலில் உள்ள Pro இல்லாமல் உருவாக்குவதற்கு சொந்த API விசை தேவை. வேறு வழங்குநரை வெளிப்படையாகத் தேர்ந்தெடுக்காவிட்டால் Pro இயல்பாக எங்கள் சேவையைப் பயன்படுத்தும். சாதனமும் மூலத்தின் மொழி மற்றும் கேள்விகளின் மொழி இரண்டும் ஆதரிக்கப்படும்போது மூல அடிப்படையிலான நினைவட்டை வரைவுகளுக்கு Apple Intelligence Pro-இல் மட்டும் கிடைக்கும். பாடங்கள், சுருக்கங்கள் மற்றும் வினாடி வினாக்களை உருவாக்க மேக இணைப்பு தேவை. Pro காலாவதியானால் Pro மூலம் உருவாக்குவது தடுக்கப்படும்; Apple கிடைக்காவிட்டால் தேர்ந்தெடுத்த Apple வழி தடுக்கப்படும். செயலி வழங்குநர்களைத் தானாக மாற்றாது. OpenAI, Anthropic, Gemini அல்லது இணக்கமான வழங்குநருடன் தனிப்பட்ட API விசையைப் பயன்படுத்துங்கள். API பயன்பாட்டிற்கு வழங்குநர் தனியாகக் கட்டணம் வசூலிப்பார். உங்கள் API விசையைப் பயன்படுத்தும்போது, தேர்ந்தெடுத்த பகுதிகளும் உருவாக்க வழிமுறைகளும் மட்டுமே நீங்கள் உறுதிப்படுத்தும் வழங்குநருக்கும் மாதிரிக்கும் நேரடியாக அனுப்பப்படும். உங்கள் விசை இந்தச் சாதனத்தின் Keychainஇல் சேமிக்கப்படும். வழங்குநர் தனது விதிமுறைகளின்படி கோரிக்கைகளை வைத்திருக்கலாம். அந்த வழங்குநரிடம் ஏற்கெனவே உள்ள நகல்களை AnyPracticeஆல் நீக்க முடியாது.

Apple Intelligence

இந்த விருப்பத்திற்கு செயலில் உள்ள Pro சந்தா தேவை. Apple Intelligence ஆதரிக்கப்படும் சாதனங்களில் மூலத்தை அடிப்படையாகக் கொண்ட நினைவட்டைகளை உருவாக்குகிறது. உருவாக்கமும் ஆதரிக்கப்படும் மொழிபெயர்ப்பும் சாதனத்திலேயே நடைபெறும்; மொழி வளங்களைப் பதிவிறக்க வேண்டியிருக்கலாம்.

AnyPractice Pro

Pro மேகச் சேவையைப் பயன்படுத்தும்போது: Pro-வில் தேர்ந்தெடுத்த உரையும் உறுதிசெய்த மூலப் பக்கங்களும் Vercel-இல் இயங்கும் AnyPractice வழியாக OpenAI-க்குச் செல்லும். சேவையகத்தில் கோப்பு நூலகம் உருவாக்காமல், அந்தக் கோரிக்கைக்காக மூலக் கோப்புகள் செயலாக்கப்படுகின்றன. Apple கட்டணங்களைச் செயலாக்குகிறது; சேவையகம் உங்கள் சந்தாவைச் சரிபார்த்து அடையாளங்காட்டிகளையும் பயன்பாட்டு எண்ணிக்கைகளையும் சேமிக்கிறது. வழங்குநர்களும் ஹோஸ்டிங் சேவைகளும் தங்கள் சொந்தக் கொள்கைகளின்படி தரவைக் கையாளுகின்றன.

சேமித்த தரவை அகற்று

ஒரு டெக்கை நீக்கினால், அதன் சேமித்த உரை, புகைப்படம் அல்லது PDF-இன் உள்ளூர் நகல், உருவாக்கிய பாடப்பொருள் மற்றும் முன்னேற்றம் இந்தச் செயலியிலிருந்து அகற்றப்படும். அதே பாடப்பொருளைப் பயன்படுத்தும் மற்ற டெக்குகள் அவற்றின் நகல்களைத் தக்கவைக்கும். «இணைப்பை அகற்று» சேமித்த தனிப்பட்ட விசையை நீக்கும். இந்தச் செயலிக்கு வெளியே உள்ள கோப்புகள், காப்புப்பிரதிகள் மற்றும் வழங்குநரிடம் உள்ள தரவு தனியானவை.

சேவைப் பதிவுகளும் வழங்குநரின் தரவுத் தக்கவைப்பும்

Pro மேகச் சேவையைப் பயன்படுத்தும்போது: Pro உறுதிசெய்த பாடப்பொருளை Vercel வழியாக OpenAI-க்கு அனுப்பும். சேவையகத்தில் படிப்புக் கோப்பு நூலகம் வைத்திருக்கவோ படிப்பு உள்ளடக்கத்தை வேண்டுமென்றே பதிவுகளில் எழுதவோ மாட்டோம். இது தரவைத் தக்கவைக்கவே மாட்டோம் என்பதல்ல: வழங்குநர் மற்றும் உள்கட்டமைப்பின் கொள்கைகள் தொடரும். OpenAI கோரிக்கைகள் store:false பயன்படுத்தும்; வழக்கமான தவறான பயன்பாட்டுக் கண்காணிப்பு உள்ளடக்கம் சட்ட/பாதுகாப்பு விதிவிலக்குகளுடன் 30 நாட்கள் வரை இருக்கலாம். சந்தா அணுகல், பாதுகாப்பு மற்றும் வரம்புகளுக்கு கையொப்பமிட்ட Apple பரிவர்த்தனைகள், நிலையான ஹாஷ் செய்யப்பட்ட சந்தா/கோரிக்கை அடையாளங்கள் மற்றும் UTC எண்ணிகள் பயன்படும். இந்த அடையாளங்கள் அநாமதேயமானவை அல்ல. தின எண்ணிகள் கடைசிப் புதுப்பிப்பின் 3 நாட்களுக்குப் பிறகும் மாத எண்ணிகள் 35 நாட்களுக்குப் பிறகும் காலாவதியாகும்; நகல் கோரிக்கைகளைக் கண்டறியும் ஹாஷ்கள் தானாகக் காலாவதியாகாது. உள்ளூர் அட்டைத் தொகுப்பை நீக்குவது இந்தப் பதிவுகள், வழங்குநர் பதிவுகள், இயக்க முறைமைக் காப்புகள் அல்லது ஆதரவு கடிதங்களை நீக்காது. சேவைத் தரவு கோரிக்கைகளுக்கு எங்களைத் தொடர்புகொள்ளுங்கள்; ரகசிய விசை அல்லது கடவுச்சொல்லை ஒருபோதும் அனுப்ப வேண்டாம்.

ஆதரவு

கற்பவர் கணக்கு, விளம்பர SDK அல்லது செயலிகளுக்கிடையேயான கண்காணிப்பு இல்லை. இந்த இணையதளம் பகுப்பாய்வு குக்கிகள் அல்லது விளம்பர நிரல்களைப் பயன்படுத்தாது. GitHub Pages வழக்கமான தள/வலையமைப்பு கோரிக்கைகளைச் செயலாக்கும். ஆதரவு மின்னஞ்சலும் நீங்கள் விரும்பி அனுப்பும் தகவல்களும் பதிலளிக்கவும் சிக்கல்களை விசாரிக்கவும் பயன்படும். பணம் செலுத்துவதை Apple கையாளும்; அட்டை விவரங்கள் அல்லது Apple கடவுச்சொற்கள் எங்களுக்குக் கிடைக்காது. AnyPractice பெரியவர்கள், பெற்றோர் மற்றும் ஆசிரியர்களுக்கானது.
