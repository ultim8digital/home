செயலி பதிப்பு, iOS பதிப்பு, தேர்ந்தெடுத்த AI இணைப்பு மற்றும் பிழைச் செய்தியைத் தெரிவியுங்கள். API விசைகள், Apple கடவுச்சொற்கள், வாங்குதல் அங்கீகார விவரங்கள் அல்லது தனிப்பட்ட ஆவணங்களை அனுப்ப வேண்டாம்.

உங்கள் பாடப்பொருள்

பாடப்பொருளை இறக்குமதி செய்யுங்கள் அல்லது ஒட்டுங்கள்; கற்றல் முறையைத் தேர்ந்தெடுத்து AI இணைப்பைச் சரிபாருங்கள். செயலில் உள்ள Pro இல்லாமல் உருவாக்குவதற்கு சொந்த API விசை தேவை. வேறு வழங்குநரை வெளிப்படையாகத் தேர்ந்தெடுக்காவிட்டால் Pro இயல்பாக எங்கள் சேவையைப் பயன்படுத்தும். சாதனமும் மூலத்தின் மொழி மற்றும் கேள்விகளின் மொழி இரண்டும் ஆதரிக்கப்படும்போது மூல அடிப்படையிலான நினைவட்டை வரைவுகளுக்கு Apple Intelligence Pro-இல் மட்டும் கிடைக்கும். பாடங்கள், சுருக்கங்கள் மற்றும் வினாடி வினாக்களை உருவாக்க மேக இணைப்பு தேவை. Pro காலாவதியானால் Pro மூலம் உருவாக்குவது தடுக்கப்படும்; Apple கிடைக்காவிட்டால் தேர்ந்தெடுத்த Apple வழி தடுக்கப்படும். செயலி வழங்குநர்களைத் தானாக மாற்றாது. சேமித்த பாடங்களும் பயிற்சியும் இணையமின்றி இயங்கும்.

படங்களும் PDFகளும்

தெளிவான, நல்ல வெளிச்சமுள்ள படத்தைப் பயன்படுத்தி அடையாளம் கண்ட உரையைச் சரிபாருங்கள். Pro பாடங்களுக்கு அசல் படம் அல்லது தேர்ந்தெடுத்த முழு PDF பக்கங்களை வெளிப்படையாக உறுதிசெய்யலாம்; முழுப் பக்கத்தில் தேர்ந்தெடுக்காத உரையும் இருக்கலாம். தனிப்பட்ட வழங்குநரும் மூல அட்டைகள் உருவாக்கமும் உரையை மட்டுமே பயன்படுத்தும்.

AnyPractice Pro — பரிந்துரைக்கப்படுகிறது

சிறந்த மாதிரிகள் மூலம் பாடங்கள், விளக்கங்கள், சுருக்கங்கள் மற்றும் பயிற்சிகளை உருவாக்குங்கள்.

Pro மேகச் சேவையைப் பயன்படுத்தும்போது: Pro-வில் UTC நாட்காட்டி மாதத்திற்கு அதிகபட்சம் 60 தொடங்கப்பட்ட உருவாக்கக் கோரிக்கைகளும் UTC நாளுக்கு அதிகபட்சம் 5 கோரிக்கைகளும் உள்ளன. சேவையின் ஒட்டுமொத்த பயன்பாட்டு மற்றும் நிதி வரம்புகள் உங்கள் தனிப்பட்ட ஒதுக்கீடு முடிவதற்கு முன்பே உருவாக்கத்தைத் தற்காலிகமாக நிறுத்தலாம். தொடங்கப்பட்ட கோரிக்கைகள் தோல்வியுற்றாலும் இடைநின்றாலும் கணக்கிடப்படும். சேமித்த பாடப்பொருள் இணையமின்றிக் கிடைக்கும்.

அமெரிக்க விலை: தானியங்கிப் புதுப்பிப்புடன் மாதம் $6.99 அல்லது ஆண்டு $49.99. உள்ளூர் விலை, கிடைக்கும் நிலை மற்றும் இறுதி விதிகள் App Store-இல் காட்டப்படும். Apple கணக்கில் நிர்வகிக்கலாம் அல்லது ரத்துசெய்யலாம்; செயலியில் வாங்கியவற்றை மீட்டெடுக்கலாம்.

செயலில் உள்ள Pro இல்லாமல் உருவாக்குவதற்கு சொந்த API விசை தேவை. வேறு வழங்குநரை வெளிப்படையாகத் தேர்ந்தெடுக்காவிட்டால் Pro இயல்பாக எங்கள் சேவையைப் பயன்படுத்தும். சாதனமும் மூலத்தின் மொழி மற்றும் கேள்விகளின் மொழி இரண்டும் ஆதரிக்கப்படும்போது மூல அடிப்படையிலான நினைவட்டை வரைவுகளுக்கு Apple Intelligence Pro-இல் மட்டும் கிடைக்கும். பாடங்கள், சுருக்கங்கள் மற்றும் வினாடி வினாக்களை உருவாக்க மேக இணைப்பு தேவை. Pro காலாவதியானால் Pro மூலம் உருவாக்குவது தடுக்கப்படும்; Apple கிடைக்காவிட்டால் தேர்ந்தெடுத்த Apple வழி தடுக்கப்படும். செயலி வழங்குநர்களைத் தானாக மாற்றாது. OpenAI, Anthropic, Gemini அல்லது இணக்கமான வழங்குநருடன் தனிப்பட்ட API விசையைப் பயன்படுத்துங்கள். API பயன்பாட்டிற்கு வழங்குநர் தனியாகக் கட்டணம் வசூலிப்பார்.

உருவாக்கிய உள்ளடக்கத்தைப் புகாரளி

AI தவறுகள் செய்யலாம். உருவாக்கப்பட்ட உள்ளடக்கத்தை ஆப்பில் திருத்தலாம் அல்லது நீக்கலாம். தீங்கு விளைவிக்கும் உள்ளடக்கத்தைப் புகாரளிக்க, தனிப்பட்ட தகவல்களைச் சேர்க்காமல் சிக்கலை விவரிக்கவும்.

சேமித்த தரவை அகற்று

ஒரு டெக்கை நீக்கினால், அதன் சேமித்த உரை, புகைப்படம் அல்லது PDF-இன் உள்ளூர் நகல், உருவாக்கிய பாடப்பொருள் மற்றும் முன்னேற்றம் இந்தச் செயலியிலிருந்து அகற்றப்படும். அதே பாடப்பொருளைப் பயன்படுத்தும் மற்ற டெக்குகள் அவற்றின் நகல்களைத் தக்கவைக்கும். «இணைப்பை அகற்று» சேமித்த தனிப்பட்ட விசையை நீக்கும். இந்தச் செயலிக்கு வெளியே உள்ள கோப்புகள், காப்புப்பிரதிகள் மற்றும் வழங்குநரிடம் உள்ள தரவு தனியானவை.
