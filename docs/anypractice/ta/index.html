புரிதல் பிறக்கட்டும்.

உங்கள் பாடப்பொருள். உங்கள் தேர்வு.

உரை கண்டறிதல் உங்கள் சாதனத்தில் இயங்குகிறது. இறக்குமதி செய்த புகைப்படங்களும் PDF-களும் உங்கள் பாடப்பொருளுடன் சாதனத்திலேயே சேமிக்கப்படுகின்றன. Pro பாடங்களுக்கு, மதிப்பாய்வு செய்து உறுதிசெய்த பிறகு புகைப்படத்தையோ தேர்ந்தெடுத்த முழு PDF பக்கங்களையோ OpenAI-க்கு அனுப்பலாம். உரை மட்டும் பயன்படுத்தும் முறைகள் மதிப்பாய்வு செய்த உரையை மட்டுமே அனுப்பும்.

AI வழங்குநர்கள்

செயலில் உள்ள Pro இல்லாமல் உருவாக்குவதற்கு சொந்த API விசை தேவை. வேறு வழங்குநரை வெளிப்படையாகத் தேர்ந்தெடுக்காவிட்டால் Pro இயல்பாக எங்கள் சேவையைப் பயன்படுத்தும். சாதனமும் மூலத்தின் மொழி மற்றும் கேள்விகளின் மொழி இரண்டும் ஆதரிக்கப்படும்போது மூல அடிப்படையிலான நினைவட்டை வரைவுகளுக்கு Apple Intelligence Pro-இல் மட்டும் கிடைக்கும். பாடங்கள், சுருக்கங்கள் மற்றும் வினாடி வினாக்களை உருவாக்க மேக இணைப்பு தேவை. Pro காலாவதியானால் Pro மூலம் உருவாக்குவது தடுக்கப்படும்; Apple கிடைக்காவிட்டால் தேர்ந்தெடுத்த Apple வழி தடுக்கப்படும். செயலி வழங்குநர்களைத் தானாக மாற்றாது. OpenAI, Anthropic, Gemini அல்லது இணக்கமான வழங்குநருடன் தனிப்பட்ட API விசையைப் பயன்படுத்துங்கள். API பயன்பாட்டிற்கு வழங்குநர் தனியாகக் கட்டணம் வசூலிப்பார்.

AnyPractice Pro — பரிந்துரைக்கப்படுகிறது

சிறந்த மாதிரிகள் மூலம் பாடங்கள், விளக்கங்கள், சுருக்கங்கள் மற்றும் பயிற்சிகளை உருவாக்குங்கள்.

Pro மேகச் சேவையைப் பயன்படுத்தும்போது: Pro-வில் UTC நாட்காட்டி மாதத்திற்கு அதிகபட்சம் 60 தொடங்கப்பட்ட உருவாக்கக் கோரிக்கைகளும் UTC நாளுக்கு அதிகபட்சம் 5 கோரிக்கைகளும் உள்ளன. சேவையின் ஒட்டுமொத்த பயன்பாட்டு மற்றும் நிதி வரம்புகள் உங்கள் தனிப்பட்ட ஒதுக்கீடு முடிவதற்கு முன்பே உருவாக்கத்தைத் தற்காலிகமாக நிறுத்தலாம். தொடங்கப்பட்ட கோரிக்கைகள் தோல்வியுற்றாலும் இடைநின்றாலும் கணக்கிடப்படும். சேமித்த பாடப்பொருள் இணையமின்றிக் கிடைக்கும்.

அமெரிக்க விலை: தானியங்கிப் புதுப்பிப்புடன் மாதம் $6.99 அல்லது ஆண்டு $49.99. உள்ளூர் விலை, கிடைக்கும் நிலை மற்றும் இறுதி விதிகள் App Store-இல் காட்டப்படும். Apple கணக்கில் நிர்வகிக்கலாம் அல்லது ரத்துசெய்யலாம்; செயலியில் வாங்கியவற்றை மீட்டெடுக்கலாம்.
