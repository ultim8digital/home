Perpustakaan lokal

Teks belajar yang diekstrak, pelajaran, kartu, dan progres Anda disimpan di aplikasi ini pada perangkat Anda. Aplikasi tidak membuat akun AnyPractice atau menyediakan sinkronisasi cloud sendiri. Cadangan perangkat mungkin menyertakan data aplikasi lokal.

Foto dan PDF

Pengenalan teks berjalan di perangkat Anda. Foto dan PDF yang diimpor juga disimpan di perangkat bersama materi Anda. Untuk pelajaran Pro, Anda dapat mengirim foto atau seluruh halaman PDF yang dipilih ke OpenAI setelah meninjau dan mengonfirmasinya. Mode teks saja hanya mengirim teks yang telah ditinjau.

Penyedia AI

Tanpa Pro aktif, pembuatan konten memerlukan kunci API Anda sendiri. Pro menggunakan layanan kami secara default kecuali Anda memilih penyedia lain secara eksplisit. Apple Intelligence hanya tersedia dengan Pro untuk draf kartu berdasarkan sumber, jika perangkat serta bahasa sumber dan pertanyaan didukung. Pembuatan pelajaran, ringkasan, dan kuis memerlukan koneksi cloud. Pro yang kedaluwarsa memblokir pembuatan melalui Pro; Apple yang tidak tersedia memblokir jalur Apple yang dipilih. Aplikasi tidak beralih penyedia secara otomatis. Gunakan kunci API pribadi dengan OpenAI, Anthropic, Gemini, atau penyedia yang kompatibel. Penyedia menagih penggunaan API secara terpisah. Dengan kunci API Anda, hanya kutipan yang dipilih dan instruksi pembuatan yang dikirim langsung ke penyedia dan model yang Anda konfirmasi. Kunci Anda disimpan di Keychain perangkat ini. Penyedia dapat menyimpan permintaan sesuai ketentuannya sendiri. AnyPractice tidak dapat menghapus salinan yang sudah disimpan oleh penyedia tersebut.

Apple Intelligence

Opsi ini memerlukan langganan Pro aktif. Apple Intelligence membuat kartu belajar berdasarkan sumber pada perangkat yang didukung. Pembuatan dan penerjemahan yang didukung berjalan secara lokal; aset bahasa mungkin perlu diunduh.

AnyPractice Pro

Saat menggunakan layanan cloud Pro: Dengan Pro, teks yang dipilih dan halaman asli yang telah Anda konfirmasi akan melewati AnyPractice di Vercel menuju OpenAI. File asli diproses untuk permintaan tersebut tanpa pustaka file di server. Apple menangani pembayaran; server memverifikasi langganan Anda dan menyimpan pengenal serta penghitung penggunaan. Penyedia dan layanan hosting menangani data sesuai kebijakan masing-masing.

Hapus data tersimpan

Hapus deck untuk menghapus teks tersimpan, salinan foto atau PDF di perangkat, materi yang dihasilkan, dan progresnya dari aplikasi ini. Deck lain yang menggunakan materi yang sama tetap menyimpan salinannya masing-masing. Hapus koneksi akan menghapus kunci pribadi yang tersimpan. File di luar aplikasi ini, cadangan, dan data di pihak penyedia dikelola secara terpisah.

Catatan layanan dan penyimpanan oleh penyedia

Saat menggunakan layanan cloud Pro: Pro meneruskan materi yang dikonfirmasi melalui Vercel ke OpenAI. Kami tidak menyimpan pustaka berkas belajar di server atau sengaja mencatat isi belajar dalam log. Ini bukan berarti tanpa penyimpanan: kebijakan penyedia dan infrastruktur tetap berlaku. Permintaan OpenAI memakai store:false; isi pemantauan penyalahgunaan bawaan dapat tersimpan hingga 30 hari dengan pengecualian hukum/keamanan. Akses langganan, keamanan, dan batas memakai transaksi Apple bertanda tangan, pengenal langganan/permintaan tetap yang di-hash, serta penghitung UTC. Pengenal ini tidak anonim. Penghitung harian kedaluwarsa 3 hari setelah pembaruan terakhir, bulanan setelah 35 hari; ringkasan pendeteksi permintaan duplikat tidak kedaluwarsa otomatis. Menghapus dek lokal tidak menghapus catatan ini, catatan penyedia, cadangan sistem operasi, atau korespondensi dukungan. Hubungi kami untuk permintaan data layanan; jangan pernah mengirim kunci rahasia atau kata sandi.

Dukungan

Tanpa akun pelajar, SDK iklan, atau pelacakan lintas aplikasi. Situs ini tidak memakai cookie analitik atau skrip iklan. GitHub Pages tetap memproses permintaan hosting/jaringan biasa. Email dukungan dan informasi yang kamu pilih untuk dikirim dipakai untuk menjawab dan menyelidiki masalah. Apple menangani pembayaran; kami tidak menerima detail kartu atau kata sandi Apple. AnyPractice ditujukan bagi orang dewasa, orang tua, dan guru.
