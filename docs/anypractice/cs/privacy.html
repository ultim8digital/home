Místní knihovna

Extrahovaný studijní text, lekce, kartičky a pokrok se ukládají v této aplikaci na vašem zařízení. Aplikace nevytváří účet AnyPractice ani neposkytuje vlastní cloudovou synchronizaci. Zálohy zařízení mohou obsahovat místní data aplikace.

Fotografie a PDF

Rozpoznávání textu probíhá na tvém zařízení. Importované fotografie a PDF se také ukládají místně s tvými materiály. U lekcí Pro můžeš po kontrole a potvrzení poslat fotografii nebo celé vybrané stránky PDF do OpenAI. Textové režimy odesílají pouze zkontrolovaný text.

Poskytovatelé AI

Bez aktivního Pro vyžaduje generování vlastní API klíč. Pro ve výchozím nastavení používá naši službu, pokud výslovně nezvolíte jiného poskytovatele. Apple Intelligence je pouze s Pro dostupnou možností pro návrhy kartiček ze zdrojů, pokud jsou podporovány zařízení i jazyk zdroje a otázek. Generování lekcí, shrnutí a kvízů vyžaduje cloudové připojení. Po vypršení Pro je generování přes Pro blokováno; nedostupnost Apple blokuje zvolenou cestu Apple. Aplikace poskytovatele automaticky nepřepíná. Použijte vlastní API klíč pro OpenAI, Anthropic, Gemini nebo kompatibilního poskytovatele. Poskytovatel účtuje využití API zvlášť. S vaším klíčem API se přímo poskytovateli a modelu, které potvrdíte, odešlou pouze vybrané úryvky a pokyny pro generování. Klíč je uložen v Keychain tohoto zařízení. Poskytovatel může požadavky uchovávat podle vlastních podmínek. AnyPractice nemůže smazat kopie, které tento poskytovatel již má.

Apple Intelligence

Tato možnost vyžaduje aktivní předplatné Pro. Apple Intelligence vytváří na podporovaných zařízeních kartičky podle zdrojů. Generování i podporovaný překlad probíhají místně; jazykové prostředky může být nutné stáhnout.

AnyPractice Pro

Při používání cloudové služby Pro: S Pro prochází vybraný text a potvrzené původní stránky přes AnyPractice na Vercelu do OpenAI. Původní soubory se zpracovávají pro daný požadavek, bez knihovny souborů na serveru. Platby zpracovává Apple; server ověřuje tvé předplatné a ukládá identifikátory a počítadla využití. Poskytovatelé a hostingové služby zpracovávají data podle svých vlastních zásad.

Odstranit uložená data

Smazáním balíčku z této aplikace odstraníš jeho uložený text, místní kopii fotografie nebo PDF, vygenerované materiály a pokrok. Jiné balíčky používající stejné materiály si své kopie ponechají. „Odebrat připojení“ smaže uložený osobní klíč. Soubory mimo tuto aplikaci, zálohy a data u poskytovatele jsou oddělené.

Záznamy služby a uchovávání u poskytovatelů

Při používání cloudové služby Pro: Pro předává potvrzené materiály přes Vercel do OpenAI. Nevedeme serverovou knihovnu studijních souborů ani záměrně nezapisujeme studijní obsah do protokolů. Nejde o nulové uchovávání: stále platí pravidla poskytovatelů a infrastruktury. Požadavky OpenAI používají store:false; obsah výchozího sledování zneužití může zůstat až 30 dní, s právními a bezpečnostními výjimkami. Přístup k předplatnému, zabezpečení a limity využívají podepsané transakce Apple, stálé hashované identifikátory předplatného a požadavků a čítače UTC. Tyto identifikátory nejsou anonymní. Denní čítače vyprší 3 dny po poslední aktualizaci, měsíční po 35 dnech; otisky pro detekci opakovaných požadavků nevyprší automaticky. Smazání místního balíčku nesmaže tyto záznamy, záznamy poskytovatelů, zálohy systému ani korespondenci s podporou. S žádostmi o data služby nás kontaktujte; nikdy neposílejte tajný klíč ani heslo.
